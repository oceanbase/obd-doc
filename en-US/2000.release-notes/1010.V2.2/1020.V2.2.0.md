# OceanBase Deployment Tool V2.2.0

## Version information

* Release date: August 2, 2023

* Version number: V2.2.0

## New features

* Supports OceanBase Database Community Edition V4.2

* Supports deployment of OceanBase Database Community Edition V4.2 on a server with 19G storage

* Supports component customization in the graphical interface

* Optimizes the startup performance of ODP on low-performance servers

* When you execute the `obd cluster redeploy` command, you need to confirm the operation again.

  <main id="notice" type='explain'>
     <h4>Note</h4>
     <p>You can add the <code>--confirm</code> parameter to the command to skip the confirmation. You can also run the <code>obd env set IO_DEFAULT_CONFIRM 1</code> command to set all subsequent commands to automatically confirm the operation.</p>
  </main>

## Bug fixes

Fixed the issue where the capacity type parameter was incorrectly identified when custom deployment was performed by using the `obd demo` command.
