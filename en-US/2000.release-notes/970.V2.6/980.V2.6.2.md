# OceanBase Deployer V2.6.2

## Version information

* Release date: March 4, 2024

* Version: V2.6.2

## Bug fixes

* Fixed the issue where unexpected errors occur when OCP Express V1.0.1 is started.

* Fixed the issue where unexpected errors may occur when you enable **More Configurations** during GUI-based deployment.

* Fixed the issue where the password cannot be left empty during an OCP upgrade.

* Fixed the issue where the authentication information of the sys tenant is not as expected when obdiag generates configurations.

* Fixed the issue where the initial synchronization authentication by rsync fails.

* Optimized the port occupation logic during precheck.
