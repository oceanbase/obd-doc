# OceanBase Deployment Tool V2.6.2

## Version information

* Release date: March 4, 2024

* Version: V2.6.2

## Bug fixes

* Fixed the issue where unexpected parameter passing may occur when opening **More Configurations** during graphical deployment.

* Fixed the issue where the frontend does not support empty passwords during OCP upgrades.

* Fixed the issue where the sys tenant authentication information is not as expected when generating configurations with obdiag.

* Fixed the issue where the initial authentication synchronization fails with rsync.

* Optimized the logic for checking port occupancy during pre-checks.
