# OceanBase Deployer V2.6.1

## Version information

* Release date: February 8, 2024

* Version: V2.6.1

## Bug fixes

* Fixed the issue where exceptions occur during OCP Express upgrade.

* Fixed the issues related to the port precheck logic of obshell.

* Fixed the issue where the `ocp.site.url` parameter of OCP is overridden.

* Fixed the issue where the task status during OCP upgrade check is abnormal.

* Enhanced the verification of tenant creation parameters.

* Optimized the memory check logic of OCP.

* Added the confirmation logic for the `obd cluster destroy` command.
