# OceanBase Deployment Tool V2.6.0

## Version information

* Release date: January 17, 2024

* Version number: V2.6.0

## New features


Supports obshell for OceanBase Database Community Edition V4.2.2.

## Bug fixes


* Fixed the issue where the error code links were incorrect when using the international edition of obd.

* Fixed the issue where the OBProxy configuration was empty when generating configuration files with obdiag.

* Fixed the issue with command completion in obdiag.

* Fixed the issue with offline log analysis in obdiag.

* Fixed the issue where collecting slog/clog logs with obdiag resulted in errors.

* Fixed the issue where login to the OBProxy node was not possible after scaling out.
