# OceanBase Deployer V2.7.0

## Version information

* Release date: March 28, 2024

* Version: V2.7.0

## Overview

* Tool software such as OceanBase Client (OBClient) and obdiag can be installed and managed by using OceanBase Deployer (obd) of this version. For more information, see [Tool commands](../../300.obd-command/400.tools-commands.md).

* The deployment of OceanBase Cloud Platform (OCP) and OCP Express is optimized, and automatic installation of the Java runtime environment (JRE) is supported.

* obd is adapted to support OceanBase Database V4.3.0 to support optimization by specifying the load type during deployment and tenant creation.

* obd is adapted to support oblogproxy V2.0.1_BP1.

* obd is adapted to support OceanBase Database Proxy (ODP) V4.2.3, and supports the `client_session_id_version` and `proxy_id` parameters to allow you to set globally unique client session IDs. For more information about the parameters, see [Description of the configuration file](../../400.user-guide/300.command-line-operations/100.configuration-file-description.md).

* obd is adapted to support the password conventions of OCP V4.2.2.

* obd is adapted to support obdiag V1.6, and supports the `obd obdiag gather scene run` and `obd obdiag rca run` commands. For more information, see [obdiag commands](../../300.obd-command/500.obdiag-command.md).

* The adaption to capacity units is enhanced. For example, obd automatically adapts to units such as GB and G based on the component.

* The metadata cleanup logic during OCP destruction is optimized.

* The component resource calculation logic during the execution of the `obd cluster autodeploy` command is optimized.

* The OCP clockdiff precheck capability is enhanced.

## Bug fixes

* Fixed the issue where the tenant password is not saved during the deployment of OCP Express.

* Fixed the issue where the deployment fails because the fingerprint needs to be manually input for verification during initial SSH fingerprint authentication.

* Fixed the issue where the password is not cleared when OCP Express is deleted and then added by using commands.

* Fixed the issue where the disk is used up when OCP is deployed in specific scenarios.

* Fixed the issue where the IP address is not as expected during the deployment of OceanBase Agent (OBAgent).

* Fixed the issue where an unexpected `ocp_site_url` value is passed in during GUI-based installation of OCP.
