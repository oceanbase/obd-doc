# OceanBase Deployment Tool V2.7.0

## Version information

* Release date: March 28, 2024

* Version: V2.7.0

## New features

* Supports the installation and management of tool software (OBClient, obdiag). For more information, see [Tool commands](../../300.obd-command/400.tools-commands.md).

* Optimizes the OCP deployment experience and supports automatic JRE installation.

* Adapts to OceanBase Database V4.3.0, supporting workload type specification during deployment and tenant creation.

* Adapts to oblogproxy V2.0.1_BP1.

* Adapts to OBProxy V4.2.3, adding the `client_session_id_version` and `proxy_id` configuration items to support globally unique Client Session ID settings. For more information, see the ODP configuration item descriptions in [Configuration file description](../../400.user-guide/300.command-line-operations/100.configuration-file-description.md).

* Adapts to the password policy of OCP V4.2.2.

* Adapts to obdiag V1.6, adding the `obd obdiag gather scene run` and `obd obdiag rca run` commands. For more information, see [Diagnosis tool commands](../../300.obd-command/500.obdiag-command.md).

* Enhances capacity unit adaptability, automatically adapting units like GB and G based on the component.

* Optimizes metadata cleanup logic during OCP destruction.

* Optimizes component resource calculation logic during `obd cluster autodeploy` command execution.

* Optimizes OCP clockdiff pre-check capabilities.

## Bug fixes

* Fixes the issue where deployment failure occurred due to manual confirmation required during the first SSH fingerprint authentication.

* Fixes the issue where OCP disk space was filled in specific scenarios.

* Fixes the issue where IP checks were non-compliant during OBAgent deployment.

* Fixes the issue where `ocp_site_url` was incorrectly passed during OCP installation via the graphical interface.
