# OceanBase Deployer V3.3.0

## Version information

* Release date: June 9, 2025

* Version: V3.3.0

* RPM version: ob-deploy-3.3.0-3

## New features

* Adapts to OceanBase Database Community Edition V4.3.5.2.

* Adds deployment and O&M of standby tenants based on archiving. For operations, see the "Physical Standby Database" chapter.

* Supports deploying OceanBase Database Enterprise Edition through the graphical interface, including both standalone and distributed forms.

* Supports creating business tenants through the graphical interface. For operations, see **Step 7: Create business tenant** in [Deploy OceanBase cluster](../../400.user-guide/200.ui-operations/200.use-ui-deploy-oceanbase.md).

* Supports deploying Prometheus and Grafana through the graphical interface.

* Supports configuring VIP/DNS when deploying ODP and OCP.

## Bug fixes

* Fixes the issue where usernames are displayed incorrectly in installation reports when installing through the graphical interface.

* Fixes the issue where directory validation is unexpected when adding components.
