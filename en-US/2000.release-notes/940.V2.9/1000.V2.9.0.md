# OceanBase Deployer V2.9.0

## Version information

* Release date: June 7, 2024

* Version: V2.9.0

* RPM version: ob-deploy-2.9.0-3

## Overview

* OceanBase Deployer (obd) allows you to deploy obconfigserver on the GUI. In this case, you must deploy obconfigserver with OceanBase Database. For more information, see **Deploy an OceanBase cluster on the GUI**.

* obd allows you to modify OceanBase Cloud Platform (OCP), obconfigserver, and oblogproxy. For more information, see [Scale out a cluster and change cluster components](../../400.user-guide/300.command-line-operations/900.expansion-and-component-changes.md).

* obd allows you to perform tuning based on scenarios when you create a tenant. For more information about the commands, see the **obd cluster tenant create** and **obd cluster tenant optimize** sections in [Cluster commands](../../300.obd-command/100.cluster-command-groups.md).

* obd allows you to clear installation packages. For more information about the commands, see the **obd mirror clean** section in [Mirror and repository commands](../../300.obd-command/200.command-group-for-mirroring-and-warehousing.md).

* obd is adapted to support obdiag V2.1.0.

* obd allows you to specify the `production_mode` and `scenario` parameters when you deploy OceanBase Database on the GUI. To configure the parameters, go to the **Cluster Configuration** page and enable **More Configurations** in the **Cluster Configuration** section.

## Bug fixes

* Fixed the issue where the upgrade path is abnormal in specific scenarios.

* Fixed the issue where the specified running user does not take effect when you deploy OCP.

* Fixed the issue where the installation package is not re-downloaded during redeployment because it is not completely downloaded in the first download.

* Fixed the issue where the verification during cluster takeover fails in specific scenarios.
