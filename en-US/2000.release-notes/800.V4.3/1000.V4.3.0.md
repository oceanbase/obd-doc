# OceanBase Deploy V4.3.0

## Version information

* Release date: March 31, 2026

* Version: V4.3.0

* RPM version: ob-deploy-4.3.0-2

## New features

* Supports the installation and deployment of seekdb. For more information, see [Deploy seekdb](../../400.user-guide/300.command-line-operations/200.deploy-component/300.start-the-seekdb-by-using-obd.md).

* Supports the primary-standby deployment of seekdb. For more information, see [Create a standby instance](../../400.user-guide/300.command-line-operations/300.manage-cluster/850.physical-standby-seekdb/100.deploy-physical-standby-seekdb.md).

* Supports the primary-standby maintenance of seekdb. For more information, see [Role switching and decoupling](../../400.user-guide/300.command-line-operations/300.manage-cluster/850.physical-standby-seekdb/200.role-switching-seekdb.md).

## Bug fixes

* Fixed the issue where the custom SSH port was invalid during the GUI-based deployment of OMS.

* Fixed the issue where the write permissions for files in the `/tmp` directory were not properly validated.
