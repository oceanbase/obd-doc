# OceanBase Deployer V2.10.0

## Version information

* Release date: September 3, 2024

* Version: V2.10.0

* RPM version: ob-deploy-2.10.0-3

## Overview

* obd is adapted to support OceanBase Database Community Edition V4.3.3.

* obd is adapted to support OceanBase Database Proxy (ODP) V4.3.1.

* obd allows you to manage components on the GUI. For more information, see [Modify components on the GUI](../../400.user-guide/200.ui-operations/600.component-change-by-ui.md).

* obd allows you to select a business type when you deploy OceanBase Database on the GUI. For more information, see the **Step 2: Deployment configuration** section in **Deploy an OceanBase cluster on the GUI**.

* The logic of the `obd cluster edit-config` command is optimized to avoid unexpected redeployment of a cluster.

* The input parameter logic of the `obd cluster restart` command is optimized to avoid unexpected overwriting of your configurations.

* The disk usage logic is optimized.

* obd allows you to query the connection information when you create a tenant.

* Test commands support automatic installation of the toolkit.

* obd allows you to run multi-thread tests for multiple scenarios by using the `obd test sysbench` command. For more information, see the **obd test sysbench** section in [Testing commands](../../300.obd-command/300.test-command-group.md).

* obd allows you to import data in direct load mode when you run the TPC-H benchmark by using the `obd test tpch` command. For more information, see the **obd test tpch** section in [Testing commands](../../300.obd-command/300.test-command-group.md).

* obd allows you to specify the `monitor_user` parameter when you deploy OceanBase Agent (OBAgent).

* obd supports automatic desensitization of logs.

## Bug fixes

* Fixed the issue where the SSH port is not as expected during automatic takeover of MetaDB when you deploy OceanBase Cloud Platform (OCP).

* Fixed the issue where the input parameters are not as expected when you restart OCP.

* Fixed the issue where the specified `obconfig_url` parameter does not take effect when you deploy OceanBase Database.

* Fixed the issue where an error occurs in dropping a directory when you run the `obd cluster destroy` command in OCP in specific scenarios.

* Fixed the issue of an unexpected re-upgrade upon interruption of an upgrade process.
