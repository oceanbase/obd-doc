# OceanBase Deployer V2.10.1

## Version information

* Release date: October 12, 2024

* Version: V2.10.1

* RPM version: ob-deploy-2.10.1-1

## Overview

* The new version improves the user experience on low-performance servers.

* The new version is compatible with OceanBase Database Community Edition V4.3.3.

* The new version supports verifying the version of OceanBase Cloud Platform (OCP) MetaDB.

* The new version optimizes the default configuration logic of components deployed by using the GUI.
