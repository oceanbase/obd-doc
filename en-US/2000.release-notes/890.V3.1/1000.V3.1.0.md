# OceanBase Deployer V3.1.0

## Version information

* Release date: January 2, 2025

* Version: V3.1.0

* RPM version: ob-deploy-3.1.0-3

## Overview

* OceanBase Deployer (obd) of this version supports the binlog service. For more information, see [Deploy the binlog service](../../400.user-guide/300.command-line-operations/355.deploy-binlog.md ) and [Binlog service commands](../../300.obd-command/550.binlog-commands.md).

* obd of this version supports the validity check on tenant names.

## Bug fixes

Fixed the issue where an OceanBase Cloud Platform (OCP) cluster, deployed by obd on multiple nodes, fails to start when a running user is specified by the `launch_user` option in the configuration file or the **Use the running user** parameter on the GUI for the cluster.
