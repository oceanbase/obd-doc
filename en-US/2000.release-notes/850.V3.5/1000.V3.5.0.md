# OceanBase Deployer V3.5.0

## Version information

* Release date: August 15, 2025

* Version: V3.5.0

* RPM version: ob-deploy-3.5.0-5

## New features

* Enhances `obd host init` command functionality: supports closing firewalls and SELinux, adjusting kernel parameters, etc. For details, see [Host commands](../../300.obd-command/570.host-commands.md).

* Adds the `obd host user init` command: supports creating users, setting passwords, modifying ulimit, etc. For command details, see [Host commands](../../300.obd-command/570.host-commands.md).


* Adds obshell Dashboard connection information display.

* Optimizes Oracle tenant scenarios.

## Bug fixes

* Fixes the issue where custom ports report errors in interactive installation scenarios.

* Fixes the issue where CPU detection fails on Kylin operating systems in interactive installation scenarios.

* Fixes the unexpected warning issue with the `observer_sys_password` parameter.

* Fixes the issue where creating standby tenants based on archive mode reports errors.
