# OceanBase Deployment Tool V2.3.1

## Version information

* Release date: October 13, 2023

* Version: V2.3.1

## Bug fixes

* Fixed the issue where the rotation upgrade check does not work as expected in special scenarios.

* Fixed the issue where the self-upgrade decompression fails in the el8 operating system.

* Fixed the issue where the `obd cluster chst` command throws unexpected exceptions when the ob-configserver component is present.

* Fixed the issue where unexpected exceptions occur when the `connection_url` is not configured for the ob-configserver component.
