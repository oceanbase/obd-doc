# OceanBase Deployer V2.3.0

## Version information

* Release date: September 15, 2023

* Version: V2.3.0

## Overview

* This version supports the network-based Physical Standby Database solution of OceanBase Database V4.2. For more information, see the [Physical Standby Database](../../400.user-guide/300.command-line-operations/300.manage-cluster/800.physical-standby-database/100.deploy-physical-standby-database.md) chapter.

* This version supports the deployment of obconfigserver. For more information, see [Deploy and use obconfigserver](../../400.user-guide/300.command-line-operations/200.deploy-component/350.deploy-ob-configserver.md).

* This version supports selecting the unit for capacity parameters during obd GUI-based deployment.
