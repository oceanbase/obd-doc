# OceanBase Deployer V3.6.0

## Version information

* Release date: September 4, 2025

* Version: V3.6.0

* RPM version: ob-deploy-3.6.0-3

## New features

* Provides complete Alertmanager component deployment and O&M support to help users efficiently receive and process monitoring alerts from Prometheus, and supports timely push of alert information through multiple common channels such as email, DingTalk, and WeChat. For deployment operations, see "Deploy Alertmanager".

* Supports setting the `enable_auto_start` parameter to implement automatic startup capability for OceanBase Database services, ensuring that the database can automatically resume operation after system restart.

* Supports component change capabilities for OceanBase Database Enterprise Edition standalone environments through the graphical operation interface, reducing O&M complexity.

* Adapts to OCP JDK 17 version.

## Product optimizations

Reduces OCP deployment startup times and improves product deployment efficiency.

## Bug fixes

* Fixes the issue where CPU instruction set precheck logic is unexpected.

* Fixes the issue where executing the `obd cluster reinstall` command on OCP components is unexpected.

* Fixes the issue where deployment cannot continue after modifying configurations when OCP deployment fails on the graphical operation interface.

* Fixes the issue where passwords are not displayed in deployment reports when deploying OceanBase Database through the graphical operation interface.

* Fixes the compatibility issue with available memory detection in interactive deployment on certain operating systems.
