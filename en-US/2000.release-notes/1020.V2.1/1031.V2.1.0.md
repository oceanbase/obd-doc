# OceanBase Deployment Tool V2.1.0

## Version information

* Release date: May 19, 2023

* Version number: V2.1.0

## New features

* Added telemetry feature. The telemetry feature may collect deployment information and send it to OceanBase after desensitization. For more information, see [Telemetry commands](../../300.obd-command/600.telemetry-commands.md).

* Added the obd obdiag command to support the oceanbase-diagnostic-tool diagnostic tool. For more information, see [Diagnostic tool commands](../../300.obd-command/500.obdiag-command.md).

* Added support for upgrading OceanBase-CE V4.0 to V4.1. For more information, see [Upgrade OceanBase Database](../../400.user-guide/300.command-line-operations/500.upgrade-components/700.update-oceanbase.md).

* Added support for English in the GUI deployment tool.

* Added support for configuring the SSH port in the GUI deployment tool.

* Added support for generating random passwords during deployment to avoid security issues caused by default or empty passwords.

* Optimized the installation progress and installation report experience in the GUI deployment tool.

* Optimized the experience in the GUI deployment tool for scenarios such as network disconnection and multiple simultaneous deployments.

## Bug fixes

* Fixed the example configuration issue.

* Fixed the issue where component information errors may occur if the backend does not exit after the GUI deployment is completed and continues to deploy.
