# OceanBase Deployer V3.2.1

## Version information

* Release date: April 30, 2025

* Version: V3.2.1

* RPM version: ob-deploy-3.2.1-4

## New features

* Supports deploying OCP using MetaDB connection strings with cluster names.

* Optimizes standalone edition deployment logs.

* Adds CPU AVX instruction set validation.

## Bug fixes

* Fixes the connection exception issue when scaling out ODP.

* Fixes the issue where dependencies are repeatedly installed when executing the `obd test` command.
