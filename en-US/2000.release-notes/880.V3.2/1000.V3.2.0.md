# OceanBase Deployer V3.2.0

## Version information

* Release date: April 01, 2025

* Version: V3.2.0

* RPM version: ob-deploy-3.2.0-2

## Overview

* OceanBase Deployer (obd) V3.2.0 adapts to OceanBase Database Standalone Edition V4.2.5.3.
* obd V3.2.0 supports password encryption. For more information, see [Password commands](../../300.obd-command/590.pwd-commands.md).
* obd V3.2.0 supports backup and restore. For more information, see Backup and restore.
* obd V3.2.0 supports initializing system parameters. For more information, see [obd cluster init4env](../../300.obd-command/100.cluster-command-groups.md).
* obd V3.2.0 allows OceanBase Database to automatically start upon boot.
* obd V3.2.0 adapts to OceanBase Cloud Platform (OCP) Enterprise Edition.
* obd V3.2.0 supports upgrading the Binlog service for OceanBase Database.
* obd V3.2.0 allows you to set a password during tenant creation. For more information, see [obd cluster tenant create](../../300.obd-command/100.cluster-command-groups.md).

## Bug fixes

* Fixed the issue where the new password of Grafana does not take effect after a password change.
* Fixed the issue where the auto-repair button on the GUI does not work.
* Fixed the issue where resources calculated for tenants are inaccurate during OCP deployment.
* Fixed the issue where the system does not respond instantly if OceanBase Database is used as the MetaDB during OCP deployment on the GUI.
* Fixed the issue where the image of an OCP deployed by using Docker is not stopped when the OCP is upgraded by using obd.
