# OceanBase Deployer V4.0.0

## Version information

* Release date: November 17, 2025

* Version: V4.0.0

* RPM version: ob-deploy-4.0.0-10

## New features

* Supports installation, deployment, and upgrade of Community Edition OMS.

* Fully adapts to Enterprise Edition Binlog Service, implementing control functions such as installation, startup, upgrade, restart, destruction of obbinlog clusters, and creation of Binlog instances.

* Adapts to OceanBase-ce upgrade to version 4.4.x.

* Visual component changes support OceanBase Database Standalone Edition, including installation or uninstallation of tools such as Alertmanager and Prometheus.

* Supports automatic registration of Alertmanager and Prometheus configuration information to obshell Dashboard.

* Implements Alertmanager support for Slack notification methods.

* Optimizes the display order of cluster custom parameter configurations such as `cpu_count`, `memory_limit`, `datafile_size`, etc., to facilitate quick user operations.

* Interactive deployment supports displaying more tenant information, such as character set, collation, time zone, and case sensitivity (MySQL tenants).

* Supports modifying cluster configuration files in `destroyed` and `configured` states.

* Adds the `obd cluster prune-config` command to support cleaning up configuration files for clusters in `destroyed` and `configured` states.

* Implements real IP address configuration for OCP single-machine multi-NIC scenarios through `Docp.host.ip=xxx`.

## Product behavior changes

* Changes OB-Dashboard to obshell Dashboard.

* `obd host init` checks/modifies `net.ipv4.ip_forward` only for OceanBase Database Standalone Edition to avoid network access exceptions in Docker environments.

## Bug fixes

* Fixes discovered security issues, upgrading the underlying frameworks and runtime environments used by obd.

  * Upgrades Node version to 20.19.5.

  * Upgrades Python version to 3.11.

* Fixes the issue where the `obd host user init` command reports errors in special scenarios.

* Fixes the issue where component names are not displayed on the page when uninstalling ocp-server-ce components through the graphical interface.
