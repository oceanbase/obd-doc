# obd V3.0.0

## Version information

* Release date: December 12, 2024

* Version: V3.0.0

* RPM version: ob-deploy-3.0.0-3

## Overview

* OceanBase Deployer (obd) of this version adapts to OceanBase Database Community Edition V4.2.5.1.

* The system architecture is upgraded to introduce the workflow orchestration mechanism.

* Installation and deployment on low-performance servers are optimized.

* The logic to automatically generate configurations is optimized.

## Bug fixes

* Fixed the issue where the memory computing logic in the precheck phase is not as expected during deployment of OceanBase Cloud Platform (OCP) on the GUI.

* Fixed the issue where some logs are skipped in desensitization.
