# OceanBase Deployer V3.4.0

## Version information

* Release date: July 14, 2025

* Version: V3.4.0

* RPM version: ob-deploy-3.4.0-2

## New features

* The `obd cluster deploy` command adds the `-i` option to simplify the configuration process through wizard-style interaction. For operations, see [Deploy OceanBase cluster](../../400.user-guide/300.command-line-operations/200.deploy-component/200.start-the-oceanbase-cluster-by-using-obd.md).

* Adds the single-machine maximum resource quick deployment command `obd pref` to complete high-performance single-machine environment deployment with one click. For command details, see [Quick deployment command](../../300.obd-command/000.obd-demo.md).

* Optimizes Oracle mode tenant management: supports custom user password settings to adapt to more business scenario requirements.

* Supports global installation of OBClient through the `obd tool install` command without additional environment configuration, improving client usability.

## Bug fixes

* Fixes the issue where the structure is unexpected during Switchover of multi-level primary-standby tenants based on archiving.

* Fixes the issue where restart does not take effect after modifying the `listen_port` parameter of the ODP component.
