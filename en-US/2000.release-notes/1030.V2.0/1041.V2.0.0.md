# OceanBase Deployment Tool V2.0.0

## Version information

* Release date: March 23, 2023

* Version number: V2.0.0

## New features

* Added the `obd web` command for GUI deployment, see [Deploy an OceanBase cluster by using the GUI](../../400.user-guide/200.ui-operations/200.use-ui-deploy-oceanbase.md) for more information.

* Added the `obd display-trace` command for viewing execution logs, see the **obd display-trace** section in [Tool commands](../../300.obd-command/400.tools-commands.md) for more information.

* Added the `obd cluster tenant show` command for viewing tenants, see the **obd cluster tenant show** section in [Cluster commands](../../300.obd-command/100.cluster-command-groups.md) for more information.

* Added the `obd mirror add-repo` command for managing repositories, see the **obd mirror add-repo** section in [Commands for mirroring and warehousing](../../300.obd-command/200.command-group-for-mirroring-and-warehousing.md) for more information.

* Added the `--generate-consistent-config` or `--gcc` option to the `obd cluster autodeploy` command for generating consistent configurations, which is disabled by default.

* Added support for deploying OBAgent V1.3.0.

* Added support for automatic tuning tests of OceanBase V4.1.0.0.

* Optimized the interactive experience after configuration changes.

* Optimized the start check process to provide progress updates, repair suggestions, and automatic fixes.

* Optimized the logic of the `obd cluster display` command to no longer require all nodes to be alive.

* Optimized the lock logic to no longer request locks for read-only commands.

* Added the `ENV_LOCK_MODE` variable for controlling lock levels, set using `obd env set ENV_LOCK_MODE`.

* Adjusted plugin invocation methods and added plugin execution spaces for information passing.

## Bug fixes

* Fixed an issue where the `system_memory` configuration could exceed `memory_limit` and still allow startup.

* Fixed an issue with dashboard exceptions during Grafana remote deployment.

* Fixed an issue where obd failed to execute TPCH/TPCC tests on OceanBase V4.0.0.0.

* Fixed example configuration issues.
