# OceanBase Deployment Tool V2.8.0

## Version information

* Release date: April 19, 2024

* Version number: V2.8.0

## New features

Supports taking over OceanBase CE clusters. For more information, see [Take over a cluster by using obd](../../400.user-guide/300.command-line-operations/400.takeover-cluster/450.takeover-cluster.md).

## Bug fixes

* Optimized the logic for handling failed OCP deployment on the GUI.

* Fixed the issue where upgrading certain versions of OceanBase Database failed.
