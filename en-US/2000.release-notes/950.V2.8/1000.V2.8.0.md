# OceanBase Deployer V2.8.0

## Version information

* Release date: April 19, 2024

* Version: V2.8.0

## Overview

You can use OceanBase Deployer (obd) to take over a cluster of OceanBase Database Community Edition. For more information, see Use obd to take over a cluster.

## Bug fixes

* Optimized the logic for processing failures of deploying OceanBase Cloud Platform (OCP) on the GUI.

* Fixed the issue of failing to upgrade OceanBase Database of specific versions.

* Fixed the issue of failing to deploy OCP Express by using the `obd demo` command.
