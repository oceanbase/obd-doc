# OceanBase Deployment Tool V4.2.0

## Version information

* Release date: February 3, 2026

* Version: V4.2.0

* RPM version: ob-deploy-4.2.0-1

## New features

* Supports creating a Binlog instance by specifying the `--rs` option with rs_list, simplifying the process of creating a Binlog instance in a single-node scenario. For more information, see the `obd binlog create` command in [Binlog service commands](../../300.obd-command/550.binlog-commands.md).

* Supports deploying OceanBase Database Enterprise Edition or Community Edition on remote nodes using the `obd perf` command, making it convenient for users to perform performance testing in remote environments without manual installation and configuration. For more information, see the `obd perf` command in [Quick deployment commands](../../300.obd-command/000.obd-demo.md).

## Bug fixes

Fixed the issue where obd failed to deploy in a system with an abnormal rsync environment.
