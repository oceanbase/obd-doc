# Overview

OceanBase Deployer (obd) V2.0.0 and later allow you to deploy and manage OceanBase Database and related components on the GUI. You can select an appropriate deployment method based on the actual situation.

* For CLI-based deployment, you need to write a configuration file. Then, obd will deploy OceanBase Database and related components based on the configuration file.

* For GUI-based deployment, you do not need to write a configuration file. Instead, configure related settings on the GUI as prompted. Then, obd will deploy OceanBase Database and related components based on the settings.
