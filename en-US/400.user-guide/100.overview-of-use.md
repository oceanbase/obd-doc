# Usage overview

obd supports deploying and managing OceanBase Database and related components through a graphical interface since V2.0.0. You can choose an appropriate deployment method based on your situation.

* Command-line operations: You need to write configuration files during deployment. obd deploys OceanBase Database and related components based on the information in the configuration files.

* Graphical interface operations: No configuration files are required. You fill in the corresponding configurations by following the page guidance, and obd deploys OceanBase Database and related components based on the configurations filled in the interface.
