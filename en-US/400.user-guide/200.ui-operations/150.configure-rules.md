# Configuration rules

This topic describes the rules for obd to automatically generate configurations when deploying OceanBase clusters through the graphical interface.

## CPU

CPU resource metrics are obtained through the following command:

```shell
grep -e 'processor\s*:' /proc/cpuinfo | wc -l
```

CPU is fixed at 16 in minimum available mode, and `cpu_count` = max(16, CPU count-2) in maximum occupancy mode.

## Memory

Memory resource metrics are obtained through the following commands:

```shell
# Total memory
grep MemTotal /proc/meminfo
# Available memory
grep MemAvailable /proc/meminfo
```

The calculation rules for memory-related configuration items are as follows:

### memory_limit

* Fixed at 6G in minimum available mode.

* `memory_limit` = max(6G, available memory*0.9) in maximum occupancy mode. It will be readjusted when disk available space is insufficient, with a minimum value of 6G.

### system_memory

* Fixed at 1G in minimum available mode.

* In maximum occupancy mode, this configuration item is adjusted according to the size of the memory_limit configuration. The corresponding relationship is shown in the following table.
  
  | memory_limit  | [6G, 8G) | [8G, 16G) | [16G, 32G) | [32G,48G) | [48G, 64G] | (64G, +∞) |
  |---------------|----------|-----------|------------|-----------|------------|-----------|
  | system_memory |  2G      |  3G       |  5G        |  7G       |  10G       | ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V2.1.0/zh-CN/10.configure-rules-01.png)       |

## Disk

Total disk size, used disk size, and available disk size can all be obtained through the following command:

```shell
df --output=size,avail,target
```

The calculation rules for disk-related configuration items are shown in the following table:

| Configuration item | Minimum available mode | Maximum occupancy mode |
|-------------------|----------------------|----------------------|
| datafile_size | Fixed at 2G | Adjusted according to the size of the `memory_limit` configuration. The corresponding relationship is: `datafile_size` = `memory_limit`*3 |
| log_disk_size | Fixed at 13G | Adjusted according to the size of the `memory_limit` configuration. The corresponding relationship is: `log_disk_size` = `memory_limit`*3 |

Note the following three points:

* When disk space is insufficient, `memory_limit` will be adjusted to ensure storage safety.

* In maximum occupancy mode, when disk space is sufficient, the OceanBase cluster will safely occupy the disk as much as possible while meeting `memory_limit`*3.

* OBServer logs also occupy a certain amount of disk space. Before calculation, the corresponding disk space will be deducted based on the mount point.
  
  * If log rotation is not enabled, 1G is reserved.
  
  * When log rotation is enabled, the total amount is calculated based on the number of logs retained and deducted.
