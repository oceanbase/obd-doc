# Overview

## Background information

OceanBase Database V2.0.0 and later allow you to deploy OceanBase Database and related components through a GUI. The GUI provides a simple configuration interface, and you can complete the deployment by following the prompts on the page. This chapter describes how to use the GUI of obd to deploy OceanBase Database, OceanBase Database components, and other OceanBase Database tools.
