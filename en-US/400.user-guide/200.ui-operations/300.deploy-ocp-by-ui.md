# Deploy OCP

This topic describes how to deploy OceanBase Cloud Platform (OCP) by using the obd graphical interface. It uses the creation of a new OceanBase Database as the MetaDB of OCP as an example.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Currently, obd supports only OCP Community Edition V4.2.1 and later and OCP Enterprise Edition V4.3.5 and later. </p>
</main>

## Terms

* OceanBase Database

  A fully self-developed, enterprise-level, native distributed database. <!-- For more information, see [OceanBase Database documentation](https://www.oceanbase.com/docs/oceanbase-database-cn). -->

* obd

  OceanBase Deployer, an installation and deployment tool for OceanBase Database. <!-- For more information, see [OceanBase Deployer documentation](../../100.what-is-obd.md). -->

* OBProxy

  OceanBase Database Proxy, a dedicated proxy server for OceanBase Database. It is also known as ODP. <!-- For more information, see [OceanBase Database Proxy documentation](https://www.oceanbase.com/docs/odp-doc-cn). -->

* OCP

  OceanBase Cloud Platform, a cloud platform for OceanBase Database. <!-- For more information, see [OceanBase Cloud Platform documentation](https://www.oceanbase.com/docs/oceanbase-ocp-cn). -->

* MetaDB

  A key component of OCP that provides underlying storage capabilities for managing metadata and monitoring data. OCP-Server calls MetaDB data to provide full lifecycle management services for OceanBase Database.

* Load balancing management

  Used for user access to OCP/OceanBase clusters. It is recommended to deploy multiple nodes of OCP/OBProxy and provide VIP/DNS addresses. If not configured, the system will default to selecting the first IP address for the connection string.

## Prerequisites

Before you start, make sure that the following conditions are met:

* You have installed obd V2.4.0 or later. We recommend that you install the latest version. For more information, see [Install obd](../../200.quick-start/100.install-obd.md).

* If you deploy an OceanBase cluster as MetaDB, make sure that the OBServer node supports the AVX instruction set (this requirement applies only to x86 servers). You can run the `lscpu | grep Flags | grep avx` command to check whether the AVX instruction set is supported.

* If you deploy an OceanBase cluster as MetaDB in an offline scenario and deploy it on an ARM server, make sure that the OBServer node supports the LSE instruction set. You can run the `lscpu | grep Flags | grep atomics` command to check whether the LSE instruction set is supported. If the OBServer node does not support the LSE instruction set, you must download an OceanBase Database installation package with the `nonlse` parameter and run the `obd mirror clone` command to upload the package to the local image library of obd.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>The OceanBase All in One package does not contain an OceanBase Database installation package with the <code>nonlse</code> parameter. </p>
  </main>

* The user and machine resources for deploying OCP meet the deployment requirements. <!-- For more information, see the [Installation planning](https://www.oceanbase.com/docs/common-ocp-1000000002078408) section in the official documentation of OceanBase Cloud. -->

* The clockdiff command is installed on the machine where OCP is to be deployed.

* The image library of obd contains the installation packages of the required components (OCP, OceanBase Database, ODP, and so on).

  If the machine where obd is installed can connect to the Internet, the installation packages of the community edition components are automatically downloaded from the remote image library. If you plan to deploy OCP Enterprise Edition, contact Technical Support to obtain the installation packages and run the `obd mirror clone` command to upload the packages to the local image library of obd. After the upload is complete, run the `obd mirror list local` command to view the installation packages in the local image library.

* The version of MetaDB must be V4.2.1 BP8 or V4.3.5 BP3. If you deploy OCP by using a new OceanBase cluster as MetaDB, make sure that the image library of obd contains the OceanBase Database software package of V4.2.1 BP8 or V4.3.5 BP3. Currently, there is no mandatory requirement for using an existing OceanBase cluster as MetaDB. We recommend that you use OceanBase Database of V4.2.1 BP8 or V4.3.5 BP3.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>The following description assumes that the machine can connect to the Internet or has the required software (OceanBase Database, OBAgent, OBProxy, and OCP) installed. </p>
</main>

## Procedure

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul>
  <li><p>The following procedure is based on the CentOS Linux 7.9 image for the x86 architecture. The operation interface may vary depending on the environment and the obd version. Please refer to the actual interface. </p></li>
  <li><p>obd supports the deployment of OCP Community Edition and OCP Enterprise Edition. This section describes how to deploy OCP Community Edition. </p></li>
  </ul>
</main>

## Step 1: Start the GUI

1. Run the `obd web` command to start the GUI and click the displayed URL to access the GUI.

   ```shell
   [admin@test001 ~]$ obd web
   start OBD WEB in 0.0.0.0:8680
   please open http://10.10.10.1:8680
   ```

   <main id="notice" type='explain'>
     <h4>Note</h4>
     <ul>
     <li>
     <p>The GUI is by default started on port 8680. You can run the <code>obd web -p &lt;PORT&gt;</code> command to specify the port. </p>
     </li>
     <li>
     <p>In an Alibaba Cloud or other cloud environment, the GUI may display an intranet IP address instead of the public IP address. You must use the correct IP address to access the GUI. </p>
     </li>
     <li>
     <p>The <code>obd web</code> command is bound to 0.0.0.0. In a multi-adapter deployment, you can access the GUI through any accessible IP address. </p>
     </li>
     <li>
     <p>You can use the nohup or screen command to run the <code>obd web</code> command in the background. </p>
     </li>
     </ul>
   </main>

2. (Optional) Move the cursor to the **Chinese** icon in the upper-right corner of the GUI and click the icon to switch the language.

   <!-- <img width="677" height="419.5" src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V2.4.0/zh-CN/200.quick-start/300.deploy-ocp-by-ui-12.png" alt="Language switch"> -->

3. Click **Start Your Trial** in the GUI. In the **Welcome to OceanBase Deployment Wizard** window, select the **OceanBase Cloud Platform** module. Move the cursor to the **<UI-TERM key="ocp-v2.Component.InstallService.Mounting">Install</UI-TERM>** button and select an installation method. Then, the **Welcome to OCP Deployment Wizard** window appears.

   You can select an OCP installation method in this window. Here, we use **Install a new OceanBase Database** as an example to introduce how to deploy OCP by using obd. <!-- For more information, see [Deploy OCP by using the GUI](https://www.oceanbase.com/docs/common-ocp-1000000004276697) in the Cloud Platform OCP documentation. -->

## Step 6: Precheck

The **<UI-TERM key="ocp-v2.Detail.TakeOver.Precheck">Precheck</UI-TERM>** page displays the system check results.
