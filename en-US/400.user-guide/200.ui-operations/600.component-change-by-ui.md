# Modify a component

This topic describes how to add or delete a component in the graphical interface.

## Prerequisites

Before you start, make sure that you meet the following conditions:

* You have installed obd V2.10.0 or later. We recommend that you install the latest version. For more information, see [Install obd](../../200.quick-start/100.install-obd.md).

* obd manages at least one running OceanBase cluster.

* You can log in to the node where the component to be added is located by using password-free SSH. <!-- For more information, see [Set up password-free SSH login](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000002016078) in the OceanBase Database documentation. -->

## Install the component

### Step 1: Start the graphical interface

1. Start the graphical interface

   Run the `obd web` command in the command line to start the graphical interface, and click the displayed address to access the graphical interface.

   ```shell
   [admin@test001 ~]$ obd web
   start OBD WEB in 0.0.0.0:8680
   please open http://10.10.10.1:8680
   ```

   <main id="notice" type='explain'>
     <h4>Note</h4>
     <ul>
     <li>
     <p>The graphical interface uses port 8680 by default. You can use the <code>obd web -p &lt;PORT&gt;</code> command to specify a port. </p>
     </li>
     <li>
     <p>In Alibaba Cloud or other cloud environments, the program may fail to obtain a public IP address and instead output an intranet IP address. In this case, you must use the correct IP address to access the graphical interface. </p>
     </li>
     <li>
     <p>The <code>obd web</code> command is bound to 0.0.0.0. In a multi-network card deployment, you can access the graphical interface through any accessible IP address. </p>
     </li>
     <li>
     <p>You can use the nohup or screen command to run the <code>obd web</code> command in the background. </p>
     </li>
     </ul>
   </main>

2. (Optional) Move the cursor to the **Chinese** character in the upper-right corner of the graphical interface and click it to switch between Chinese and English interfaces based on the displayed language. The following figure shows the language switching interface. 

   <!-- <img width="677" height="419.5" src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V2.4.0/zh-CN/200.quick-start/300.deploy-ocp-by-ui-12.png" alt="Language switching"> -->

3. In the interface, click **Start Your Experience**. In the **Welcome to the OceanBase Deployment Wizard** interface, select the **Component Management** module. Move the cursor to the **Manage** button and select the corresponding component management method. In this example, select **Component Installation**.

### Step 2: Deploy and configure components

You can select the components to be installed on the **Deployment Configuration** page. The following figure shows the **Deployment Configuration** page. 

<!-- ![Deployment configuration](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V3.6.0/deploy-by-gui/600.component-change-by-ui-03.png) -->

| Module |  Description     |
|--------|-----------|
| Deployment Target | Select the cluster to add the component. Click the dropdown list below **<UI-TERM key="ocp-performance-report.pages.AWR.Cluster">Cluster</UI-TERM>** to display all running clusters managed by obd. You can click the name of the target cluster to add the component to the cluster.  |
| Select Deployment Components | After you select a cluster, the components already deployed on the cluster and the components that can be added are displayed here. You can click the check box before the name of a component to install the component. The component version is fixed to the latest version. You can click **<UI-TERM key="ocp-v2.Settings.Credential.LearnMore">Learn More</UI-TERM>** after the name of a component to jump to the documentation of the component.  |

After you select the components to be deployed, click **<UI-TERM key="ocp-v2.component.StepsMoveOutCluster.Step1.NextStep">Next</UI-TERM>** in the lower-right corner to go to the **Component Configuration** page.

### Step 3: Configure components

You can configure the nodes, ports, and other parameters of the components to be deployed on the **Component Configuration** page. The following figure shows the **Component Configuration** page. 

<!-- ![Component configuration](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V3.6.0/deploy-by-gui/600.component-change-by-ui-04.png) -->

| Module |  Description     |
|--------|-----------|
| Component Node Configuration | You can configure the IP address of the selected component in this module. After you enter an IP address, press the Enter key to configure multiple IP addresses. We recommend that you use an IP address other than <code>127.0.0.1</code>.<main id="notice" type='explain'><h4>Note</h4><p>The AlertManager node supports only a single IP address. </p></main> |
| Deployment User | The username is the username used to deploy the current cluster, and cannot be modified. You must ensure that the user exists on each host and has the corresponding directory permissions.  |
| Software Path Configuration | The default value is the installation directory of the current cluster. You can customize the software path. The path must be an absolute path starting with `/` and can contain only letters, numbers, and special characters (`-_:@/.`).  |
| Component Configuration  | Configure the ports and passwords of the selected component. For more information about the ports and passwords, see **Step 4: Configure the cluster** in [Deploy an OceanBase cluster by using the graphical interface](200.use-ui-deploy-oceanbase.md).|
| More Configurations  | You can click the expand icon before **<UI-TERM key="ocp-v2.src.component.AddUnitSpecModal.MoreConfigurations">More Settings</UI-TERM>** to view the parameters of the component. You can configure the parameters by using the automatically assigned values or customize the parameters.<main id="notice" type='explain'><h4>Note</h4><p>If you have configured multiple nodes for the <b>obconfigserver</b> node in the <b>Component Node Configuration</b> module, you must configure the load balancing before you click the <b>More Configurations</b> button to configure <code>vip_address</code> and <code>vip_port</code>. Otherwise, an error will be returned during the precheck. </p></main> |

After you configure all parameters of the component, click **<UI-TERM key="ocp-v2.Credential.Component.ImportModal.NextStep">Next</UI-TERM>** in the lower-right corner to go to the **<UI-TERM key="ocp-v2.Cluster.Import.Precheck">Precheck</UI-TERM>** page.

### Step 4: Perform a precheck

On the **<UI-TERM key="ocp-v2.Cluster.Import.Precheck">Precheck</UI-TERM>** page, view all the configuration information. If you find an issue, click **<UI-TERM key="ocp-v2.component.StepsMoveOutCluster.Step2.PreviousStep">Previous</UI-TERM>** to modify it. After you confirm that no issues exist, click **<UI-TERM key="ocp-v2.Detail.TakeOver.Precheck">Precheck</UI-TERM>** to perform the precheck. 

If the precheck fails, you can choose **<UI-TERM key="ocp-v2.page.Host.AutomaticRepair.1">Auto Repair</UI-TERM>** (for the check items that can be automatically repaired) or click **View More Solutions** to jump to the error code documentation and modify the configurations based on the documentation. After you modify all the errors, click **<UI-TERM key="ocp-v2.Cluster.Import.ReCheck">Recheck</UI-TERM>** to perform the precheck again. 

<!-- ![Precheck](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V2.10.0/zh-CN/200.ui-operations/600.component-change-by-ui-06.png) -->

After the precheck passes, click **Deploy** to start the deployment of the component.

### Step 5: Deploy

<!-- ![Deploy](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V3.6.0/deploy-by-gui/600.component-change-by-ui-05.png) -->

The following table describes the deployment details:

* If you deployed the OBProxy component, you can copy the displayed connection string and execute it in the CLI to connect to ODP as the root@proxysys user.

* If you deployed a component with a graphical interface, such as Prometheus, Grafana, or Alertmanager, you can click the connection string of the component to jump to the login page of the component. You can log in by using the account and password displayed on the deployment page.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>In Alibaba Cloud or other cloud environments, the program may fail to obtain the public IP address and output the internal IP address instead. In this case, you need to use the correct IP address to access the graphical interface. </p>
  </main>

* In the **Deployment Report** section, you can click the expand icon before the name of a component to view the deployment log of the component. When you hover the pointer over **View Details** in the component list, the command to view the component log is displayed. You can click the copy icon after the command to copy the command. After the command is copied, you can execute it in the central control node to view the log location of the component.

* You can click **Copy Info** to copy the account and password of all deployed components. After the information is copied, click **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">Complete</UI-TERM>** to exit the deployment program.

## Uninstall a component

### Step 1: Start the graphical interface

1. Start the graphical interface

   Run the `obd web` command in the CLI to start the graphical interface, and click the displayed address to access the graphical interface. The address is shown in the following example.

   ```shell
   [admin@test001 ~]$ obd web
   start OBD WEB in 0.0.0.0:8680
   please open http://10.10.10.1:8680
   ```

   <main id="notice" type='explain'>
     <h4>Note</h4>
     <ul>
     <li>
     <p>The graphical interface uses port 8680 by default. You can run the <code>obd web -p &lt;PORT&gt;</code> command to specify a port.</p>
     </li>
     <li>
     <p>If you use Alibaba Cloud or another cloud service, the system may fail to obtain a public IP address and output an intranet IP address. In this case, you need to use the correct public IP address to access the graphical interface.</p>
     </li>
     <li>
     <p>The <code>obd web</code> command is bound to 0.0.0.0. In a multi-NIC deployment, you can access the graphical interface through any accessible IP address.</p>
     </li>
     <li>
     <p>You can use the nohup or screen command to run the <code>obd web</code> command in the background.</p>
     </li>
     </ul>
   </main>

2. (Optional) Place the cursor on the **Chinese** label in the upper-right corner of the graphical interface and click the label to switch between the Chinese and English interfaces based on the displayed language. The following figure shows the interface after the language is switched to English.

   <!-- <img width="677" height="419.5" src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V2.4.0/zh-CN/200.quick-start/300.deploy-ocp-by-ui-12.png" alt="Language switch"> -->

3. In the graphical interface, click **Start Your Experience**. In the **Welcome to OceanBase Deployment Wizard** interface, select the **Component Management** module. Place the cursor on the **Manage** button and select the **Component Uninstallation** option.

### Step 2: Select a component to uninstall

You can select a component to uninstall in the **Uninstall Configuration** interface. The **Deployment Configuration** interface is as follows. The following figure shows the **Uninstall Configuration** interface.

<!-- ![Uninstall configuration](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V3.6.0/deploy-by-gui/600.component-change-by-ui-08.png) -->

| Module |  Description     |
|--------|-----------|
|  Uninstall Target | Select the cluster from which you want to uninstall a component. Click the drop-down list below **<UI-TERM key="ocp-v2.component.alarm.AlarmTargetLabel.Cluster">Cluster</UI-TERM>** to view all running clusters managed by obd. You can click the name of the cluster from which you want to uninstall a component.  |
|  Select Uninstall Component  | After you select a cluster, the components that can be uninstalled from the cluster are displayed. You can click the check box before a component to select whether to uninstall the component. By default, all components are selected. You can click **<UI-TERM key="ocp-v2.Settings.Credential.LearnMore">Learn More</UI-TERM>** after the name of a component to view the documentation of the component.<main id="notice" type='explain'><h4>Note</h4><p>Currently, you cannot uninstall obconfigserver. </p></main>  |

After you select the component to uninstall, click **<UI-TERM key="ocp-v2.src.constant.backup.Uninstall">Uninstall</UI-TERM>** in the lower-right corner. In the confirmation dialog box that appears, click **<UI-TERM key="ocp-v2.Detail.ResourceManager.CreateResourcePlan.Ok">OK</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.src.constant.backup.Uninstall">Uninstall</UI-TERM>** interface.

### Step 3: Uninstall the component

The **Uninstall** interface displays the progress and result of the component uninstallation. You can view the **Uninstall Status** column to determine whether the component is successfully uninstalled. Place the cursor on **View Running Log** in the **Action** column of the component to view the uninstallation log of the component. The following figure shows the **Uninstall** interface.

<!-- ![Uninstall result](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V3.6.0/deploy-by-gui/600.component-change-by-ui-09.png) -->
