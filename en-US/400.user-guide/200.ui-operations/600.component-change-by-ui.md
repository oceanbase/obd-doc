# Change components

This topic describes how to add or delete components in the graphical interface.

## Prerequisites

Before you start, make sure that you have met the following conditions:

* You have installed obd V2.10.0 or later. We recommend that you install the latest version. For more information, see [Install obd](../../200.quick-start/100.install-obd.md).

* obd manages at least one running OceanBase cluster.

* You can log in to the node where the component to be added is located by using password-free SSH.

## Install the component

### Step 1: Start the graphical interface

1. Start the graphical interface

   Run the `obd web` command in the command line to start the graphical interface, and click the provided address to access it.

   ```shell
   [admin@test001 ~]$ obd web
   start OBD WEB in 0.0.0.0:8680
   please open http://10.10.10.1:8680
   ```

   <main id="notice" type='explain'>
     <h4>Note</h4>
     <ul>
     <li>
     <p>The graphical interface by default uses port 8680. You can use the <code>obd web -p &lt;PORT&gt;</code> command to specify the port, which must be in the range [1025, 65535].</p>
     </li>
     <li>
     <p>In Alibaba Cloud or other cloud environments, the program may fail to obtain a public IP address and instead output an internal IP address. This IP address is not a public IP address, so you need to use the correct IP address to access the graphical interface.</p>
     </li>
     <li>
     <p>The <code>obd web</code> command is bound to 0.0.0.0. In a multi-network card deployment, you can access the graphical interface using any accessible IP address.</p>
     </li>
     <li>
     <p>You can use the nohup or screen command to run the <code>obd web</code> command in the background.</p>
     </li>
     </ul>
   </main>

2. (Optional) Place the cursor on the **Chinese** character in the upper-right corner of the graphical interface and click to switch between Chinese and English interfaces based on the displayed language.

   <!-- <img width="677" height="419.5" src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V2.4.0/zh-CN/200.quick-start/300.deploy-ocp-by-ui-12.png" alt="Language switch"> -->

3. Click **Start Your Trial** on the interface, and in the **Welcome to the OceanBase Deployment Wizard** window, select the **Component Management** module. Place the cursor on the **Manage** button and select the corresponding component management method. In this case, select **Component Installation**.

### Step 2: Deployment configuration

You can select the components to be installed on the **Deployment Configuration** page. The **Deployment Configuration** page contains the following information.

<!-- ![Deployment configuration](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V3.6.0/deploy-by-gui/600.component-change-by-ui-03.png) -->

| Module | Description |
|--------|-----------|
| Deployment Object | Select the cluster to add the component. Click the dropdown list below **<UI-TERM key="ocp-v2.Cluster.Component.WaterLevel.Cluster">Cluster</UI-TERM>** to display all running clusters managed by obd. Click the name of the corresponding cluster to add the component to it. |
| Select Deployment Components | After you select a cluster, this section displays the components deployed in the cluster and the components that can be added. Click the checkbox before the corresponding component to select whether to install it. The component version is fixed to the latest version. Click **<UI-TERM key="ocp-v2.Settings.Credential.LearnMore">Learn More</UI-TERM>** after the corresponding component to view its documentation. |

After you select the deployment components, click **<UI-TERM key="ocp-v2.Cluster.Import.Next">Next</UI-TERM>** in the lower-right corner to go to the **Component Configuration** page.

### Step 3: Component configuration

You can configure the nodes, ports, and other related settings for the components to be deployed on the **Component Configuration** page. The component deployment page contains the following information.

<!-- ![Component configuration](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V3.6.0/deploy-by-gui/600.component-change-by-ui-04.png) -->

| Module | Description |
|--------|-----------|
| Component Node Configuration | You can configure the IP address of the selected component in this section. After you enter an IP address, press Enter to configure multiple node IP addresses. We recommend that you use an IP address other than <code>127.0.0.1</code>.<main id="notice" type='explain'><h4>Note</h4><p>The AlertManager node supports only a single IP address.</p></main> |
| Deployment User | The username is the username used to deploy the current cluster and cannot be modified. Ensure that the user exists on each host and has the corresponding directory permissions.  |
| Software Path Configuration | The default value is the installation directory of the current cluster. You can customize the software path, which must be an absolute path starting with `/` and can contain only letters, numbers, and special characters (`-_:@/.`).  |
| Component Configuration  | Configure the port and password of the selected component. For more information about the ports and passwords, see **Step 4: Cluster configuration** in [Deploy an OceanBase cluster by using the graphical interface](200.use-ui-deploy-oceanbase.md).|
| More Configurations  | You can click the expand icon before **<UI-TERM key="ocp-v2.src.component.AddUnitSpecModal.MoreConfigurations">More Settings</UI-TERM>** to view the corresponding component parameters. You can use the automatically assigned values or customize the parameters.<main id="notice" type='explain'><h4>Note</h4><p>If you configure multiple nodes for the <b>obconfigserver</b> node in the <b>Component Node Configuration</b> section, you must configure the load balancer in advance and click <b>More Configurations</b> on this page to configure <code>vip_address</code> and <code>vip_port</code>. Otherwise, an error will be reported during the precheck.</p></main> |

After you configure all the parameters, click **<UI-TERM key="ocp-v2.Detail.TakeOver.Next">Next</UI-TERM>** in the lower-right corner to go to the **<UI-TERM key="ocp-v2.Detail.TakeOver.Precheck">Precheck</UI-TERM>** page.

### Step 4: Precheck

On the **<UI-TERM key="ocp-v2.Detail.TakeOver.Precheck">Precheck</UI-TERM>** page, view all the configuration information. If you find any issues, click **<UI-TERM key="ocp-v2.component.StepsMoveOutCluster.Step2.PreviousStep">Previous</UI-TERM>** to modify them. After you confirm that all the configurations are correct, click **<UI-TERM key="ocp-v2.Cluster.Import.Precheck">Precheck</UI-TERM>** to start the precheck.

If the precheck fails, you can click **<UI-TERM key="ocp-v2.page.Host.AutomaticRepair.1">Auto Repair</UI-TERM>** (for check items that can be automatically repaired) or click **View More Solutions** to go to the error code documentation and modify the configurations based on the documentation. After you modify all the errors, click **<UI-TERM key="ocp-v2.Detail.TakeOver.ReCheck">Recheck</UI-TERM>** to start the precheck again.

<!-- ![Precheck](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V2.10.0/zh-CN/200.ui-operations/600.component-change-by-ui-06.png) -->

After the precheck passes, click **Deploy** to start the deployment of the component.

### Step 5: Deploy

<!-- ![Deploy](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V3.6.0/deploy-by-gui/600.component-change-by-ui-05.png) -->

Where:

* If you deployed the OBProxy component, after the deployment is successful, you can copy the displayed connection string and execute it in the CLI to connect to ODP as the root@proxysys user.

* If you deployed a component with a graphical interface, such as Prometheus, Grafana, or Alertmanager, you can click the corresponding connection string to jump to the login page of the component. You can use the account and password displayed on the deployment page to log in.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>In an Alibaba Cloud or other cloud environment, the program may fail to obtain the public IP address and instead output the internal IP address. This IP address is not a public IP address. You need to use the correct IP address to access the graphical interface.</p>
  </main>

* In the **Deployment Report**, click the expand icon before the corresponding component to view the deployment logs. When you hover over **View Details** in the component list, the command to view the component logs is displayed. Click the copy icon next to the command to copy it. After copying, you can execute the command on the central control node to view the log location of the component.

* Click **Copy Information** to copy and save the account and password of all deployed components. Then, click **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">Complete</UI-TERM>** to exit the deployment program.

## Uninstall a component

### Step 1: Start the graphical interface

1. Start the graphical interface

   Run the `obd web` command in the CLI to start the graphical interface. Click the displayed address to access the graphical interface.

   ```shell
   [admin@test001 ~]$ obd web
   start OBD WEB in 0.0.0.0:8680
   please open http://10.10.10.1:8680
   ```

   <main id="notice" type='explain'>
     <h4>Note</h4>
     <ul>
     <li>
     <p>The graphical interface uses port 8680 by default. You can use the <code>obd web -p &lt;PORT&gt;</code> command to specify the port. The port value must be in the range [1025, 65535].</p>
     </li>
     <li>
     <p>In Alibaba Cloud or other cloud environments, the program may fail to obtain the public IP address and output the internal IP address. In this case, you must use the correct IP address to access the graphical interface.</p>
     </li>
     <li>
     <p>The <code>obd web</code> command is bound to 0.0.0.0. In a multi-network interface deployment, you can access the graphical interface through any accessible IP address.</p>
     </li>
     <li>
     <p>You can use the nohup or screen command to set the <code>obd web</code> command to run in the background.</p>
     </li>
     </ul>
   </main>

2. (Optional) Move the cursor to the **Chinese** character in the upper-right corner of the graphical interface and click the displayed language to switch between the Chinese and English interfaces.

   <!-- <img width="677" height="419.5" src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V2.4.0/zh-CN/200.quick-start/300.deploy-ocp-by-ui-12.png" alt="Language switch"> -->

3. Click **Start the Experience** in the operation interface. In the displayed **Welcome to OceanBase Deployment Wizard** interface, select the **Component Management** module. Move the cursor to the **Manage** button and select the component management method based on the displayed options. Here, select **Component Uninstallation**.

### Step 2: Uninstall the component

You can select the component to be uninstalled in the **Uninstall Configuration** interface. The content of the **Deployment Configuration** interface is as follows.

<!-- ![Uninstall configuration](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V3.6.0/deploy-by-gui/600.component-change-by-ui-08.png) -->

| Module | Description |
|--------|-----------|
|  Uninstall Object | Select the cluster from which you want to uninstall the component. Click the drop-down arrow below **<UI-TERM key="ocp-v2.src.component.TenantLabel.Cluster">Cluster</UI-TERM>** to display all running clusters managed by obd. Click the name of the target cluster to uninstall the component from the cluster. |
|  Select Uninstall Component  | After you select the cluster, the components that can be uninstalled from the cluster are displayed here. Click the check box before the component name to select whether to uninstall the component. By default, all components are selected. Click **<UI-TERM key="ocp-v2.Settings.Credential.LearnMore">Learn More</UI-TERM>** after the component name to view the documentation of the component.<main id="notice" type='explain'><h4>Note</h4><p>Currently, you cannot uninstall obconfigserver. </p></main>  |

After you select the component to be uninstalled, click **<UI-TERM key="ocp-v2.src.constant.backup.Uninstall">Uninstall</UI-TERM>** in the lower-right corner. In the confirmation dialog box that appears, click **<UI-TERM key="ocp-v2.page.Information.Ok">OK</UI-TERM>** to enter the **<UI-TERM key="ocp-v2.src.constant.backup.Uninstall">Uninstall</UI-TERM>** interface.

### Step 3: Uninstall

The uninstall interface displays the progress and result of the component uninstallation. You can view the **Uninstall Status** column of the component to determine whether the uninstallation is successful. Move the cursor to the **View Running Log** option in the **Actions** column of the component to view the uninstallation log.

<!-- ![Uninstall result](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V3.6.0/deploy-by-gui/600.component-change-by-ui-09.png) -->
