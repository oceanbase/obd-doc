# Cluster diagnotistics

This topic describes how to collect diagnostic information of an OceanBase cluster by using OceanBase Deployer (obd) commands.

obd is integrated with OceanBase Diagnostic Tool (obdiag). You can run obdiag commands in obd to scan and collect diagnostic information such as OceanBase Database logs, SQL audit information, and OceanBase Database process stack information. For more information about obdiag, visit the [obdiag repository on GitHub](https://github.com/oceanbase/obdiag).

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul>
  <li>
  <p>To use obd commands to collect diagnostic information of an OceanBase cluster, make sure that the cluster is managed by obd. Otherwise, obd cannot obtain the cluster information. By default, a cluster deployed by using obd is managed by obd. For a cluster not deployed with obd, you first need to use obd to take over the cluster. For more information, see <a href='../300.command-line-operations/450.takeover-cluster.md'>Use obd to take over a cluster</a>. </p>
  </li>
  <li>
  <p>For more information about the commands used in this topic, see <a href="../../300.obd-command/500.obdiag-command.md">obdiag commands</a>. </p>
  </li>
  </ul>
</main>

## Prerequisites

You have installed obdiag by using the `obd obdiag deploy` command.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>Different <code>obd obdiag</code> commands support different versions of OceanBase Database and OceanBase Database Proxy (ODP). If you run the commands in unsupported versions, error logs are generated. </p>
</main>

## Examples

### Information collection

You can run the `obd obdiag gather` command to collect diagnostic information of an OceanBase cluster. For more information, see the **obd obdiag gather** section in [obdiag commands](../../300.obd-command/500.obdiag-command.md).

This example shows how to collect logs of an OceanBase cluster.

```shell
obd obdiag gather log obtest --scope observer --from "2024-08-13 16:25:00" --to "2024-08-13 18:30:00" --grep STORAGE --encrypt true
```

### Cluster inspection

You can use `obd obdiag check` commands to inspect the status of an OceanBase cluster. The inspection process analyzes the cluster from perspectives of the system kernel parameters and internal tables, identifies the causes of existing or possible exceptions, and provides O&M suggestions.

You can use the `--cases` option to specify tasks in the commands. You can run the `obdiag check list` command to query supported tasks.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>You can manually write tasks. For more information, see the <b>Tutorial for writing a task</b> section in <a href="https://en.oceanbase.com/docs/common-obdiag-en-10000000001574823">Use obdiag to inspect an OceanBase cluster</a>. </p>
</main>

```shell
/home/admin/oceanbase-diagnostic-tool/obdiag check list
```

By default, obdiag is installed in the home directory of obd. You must specify the actual installation path of obdiag. The output is as follows:
