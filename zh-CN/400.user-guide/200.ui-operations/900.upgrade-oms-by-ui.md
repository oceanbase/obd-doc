# 升级 OMS

本文介绍如何通过 obd 的图形化界面操作升级 OMS。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>目前 obd 仅支持升级 OMS 社区版。</p>
</main>

## 前提条件

在开始之前，请确保您已安装 obd V4.1.0 或之后版本，建议安装最新版本，详细信息请参考 [安装 obd](../../200.quick-start/100.install-obd.md)。

## 操作步骤

### 步骤一：获取升级所需安装包

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>如待升级的 OMS 为多节点 OMS，每个节点都需要执行如下操作。</p>
</main>

1. 下载安装包

   访问 [OceanBase 软件下载中心](https://www.oceanbase.com/softwarecenter)，搜索 **OceanBase 迁移服务**，根据实际情况下载所需安装包，并将安装包上传至 obd 中控机器任一目录下。

2. 加载下载的 OMS 安装包至 Docker 容器的本地镜像仓库

   ```shell
   [admin@test001 ~]$ sudo docker load -i oms_4.2.12-ce.tar.gz
   ```

3. 验证加载是否成功

   ```shell
   [admin@test001 ~]$ sudo docker images
   ```

   输出如下：

   ```shell
   REPOSITORY                                    TAG                 IMAGE ID       CREATED        SIZE
   reg.docker.alibaba-inc.com/oceanbase/oms-ce   feature_4.2.11_ce   26f5f1554fc5   2 months ago   12.5GB
   reg.docker.alibaba-inc.com/oceanbase/oms-ce   feature_4.2.12_ce   28fddcdaf8a0   2 days ago     12.5GB
   ```

### 步骤二：关闭 HA

HA 指高可用模块（High Available，简称 HA），为数据传输链路的稳定性和连续性提供保障。升级前需禁用 HA 功能，如果开启了 HA 功能，请先参考如下步骤关闭 HA：

* 登录 OMS 社区版控制台。

* 在左侧导航栏，单击 **系统管理** > **系统参数**。

* 在 **系统参数** 页面，找到 `ha.config`。

* 单击该参数名称 **取值** 后的编辑图标。

* 在 **修改取值** 对话框中，设置 `enable` 为 `false`，关闭 HA 功能。

### 步骤三：启动升级程序

1. 启动升级

   ```shell
   [admin@test001 ~]$ obd web upgrade
   ```

   输出如下，浏览器中访问输出中的 IP 地址即可进入升级向导页面，单击 **开始升级**。

   ```shell
   start OBD WEB in 0.0.0.0:8680
   please open http://10.10.10.1:8680/#/updateWelcome
   ```

   <main id="notice" type='explain'>
     <h4>说明</h4>
     <ul>
     <li>
     <p>白屏界面默认使用 8680 端口，您可使用 <code>obd web upgrade -p &lt;PORT&gt;</code> 命令指定端口。</p>
     </li>
     <li>
     <p>在阿里云或其他云环境下，可能出现程序无法获取公网 IP，从而输出内网地址的情况，此 IP 非公网地址，您需要使用正确的地址访问白屏界面。</p>
     </li>
     <li>
     <p><code>obd web</code> 命令绑定在 0.0.0.0 上，在多网卡部署的情况下，您可通过任意一个可访问的 IP 访问白屏界面。</p>
     </li>
     </ul>
   </main>

2. 选择升级产品

   在显示的 **欢迎使用 OceanBase 升级向导** 界面选择 **OceanBase 数据迁移** 模块，单击 **升级** 按钮，即可开始升级 OMS 的操作。

### 步骤四：升级 OMS

obd 同时支持升级非 obd 部署的 OMS，本节按照待升级 OMS 的原部署方式分为 **obd 部署** 和 **非 obd 部署** 两种方法进行介绍，您可根据实际情况选择合适的升级操作。

:::tab

tab obd 部署

1. 升级配置

   您可在 **升级配置** 页面选择待升级 OMS 的部署名称、升级的目标版本及升级方式，具体介绍如下。

   ![升级配置](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V4.1.0/900.update-oms-01.png)

   | 参数  | 说明  |
   |------|--------|
   | 原部署方式 | 根据待升级 OMS 的部署方式选择 **obd 部署** 或 **非 obd 部署**。 |
   | 部署名称  | 通过下拉列表选择待升级 OMS 的部署名称。可通过在命令行中执行 `obd cluster list` 查看部署名称（`Name` 列字段）。 |
   | 目标版本  | 通过下拉列表选择升级的目标版本。  |
   | 升级方式  | 支持 **停服升级** 和 **在线升级** 两种升级方式：<ul><li><b>停服升级</b>：通过部署新版镜像容器来替换旧版容器，升级过程中运行链路将出现短暂中断。</li><li><b>在线升级</b>：在原有容器内直接替换组件包实现升级，确保运行链路全程无中断。</li></ul>  |
   | 存放升级文件路径 | 仅在选择 **在线升级** 方式时展示，支持自定义。自定义路径时需配置为以 `/` 开头的绝对路径，且只能包含字母、数字和特殊字符（<code>-_:@/.</code>）。 |

2. 配置确认

   **配置确认** 页面会展示您在 **升级配置** 页面填写的信息，您需检查并确认配置信息是否正确。若存在错误配置，可单击 **上一步** 返回 **升级配置** 页面进行修改；确认无误后，可单击 **下一步** 开始预检查。

   ![配置确认](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V4.1.0/900.update-oms-02.png)

3. 预检查

   若检查通过，可单击 **下一步** 配置数据备份信息；若检查失败，支持对失败项进行修复或忽略。

   * 若选择修复，待修复完成后单击 **重新检查**，系统将重新执行环境预检查程序。

   * 若选择忽略，单击 **忽略全部未通过项**，此时未通过的检查项 **检查状态** 将变更为 **已忽略**，可单击 **下一步** 配置数据备份信息。

   <main id="notice" type='notice'>
     <h4>注意</h4>
     <p>忽略全部未通过项可能会导致升级失败，建议您修复检查失败项后再进行下一步。</p>
   </main>

   ![预检查](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V4.1.0/900.update-oms-03.png)

4. 数据备份

   您可在 **数据备份** 页面选择是否备份关键元信息数据，并设置备份路径（如需备份）。OMS 升级过程中将根据升级需要对元信息及监控数据进行变更，变更操作不可逆，建议对元信息及监控数据进行备份，避免因升级导致的不可预知风险。

   ![数据备份](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V4.1.0/900.update-oms-04.png)

   | 参数  | 说明  |
   |-------|-------|
   | 备份方式 | 可通过下拉列表选择 **备份关键元信息数据** 或 **不备份**。 |
   | 备份路径  | 仅在选择 **备份关键元信息数据** 时展示，需指定为当前 obd 所在节点的本地路径，并保证可用空间至少 2 GiB 以上。支持自定义，自定义路径时需配置为以 `/` 开头的绝对路径，且只能包含字母、数字和特殊字符（<code>-_:@/.</code>）。</br>路径设置完成后需单击路径后的 **校验** 按钮，校验路径是否符合要求。 |

   <main id="notice" type='explain'>
     <h4>说明</h4>
     <p>选择 <b>备份关键元信息数据</b> 方式时，备份路径校验通过后才可单击 <b>下一步</b>。单击 <b>下一步</b> 后，obd 将弹窗进行数据备份，备份完成后会自动进入到 <b>OMS 升级</b> 页面。</p>
   </main>

5. OMS 升级

   升级过程中，**OMS 升级** 页面会展示升级日志。升级成功后，您可在页面中执行如下操作：

   * 单击 **升级报告** 后的展开按钮，查看升级日志。
   * 单机备份文件保存地址后的复制按钮，保存备份文件路径。
   * 单击 **去体验新版** 按钮，在新开页面打开 OMS 登录页面。

     <main id="notice" type='explain'>
       <h4>说明</h4>
       <p>在阿里云或其他云环境下，可能出现程序无法获取公网 IP，从而访问内网地址的情况，此时将无法正常展示 OMS 登录页面。</p>
     </main>

   * 单击 **退出**，并二次确认后退出 OMS 升级程序。
  
   若部署失败，您可选择单击 **重新升级**，obd 程序会尝试重新执行失败的升级步骤；也可选择单击 **退出页面**，退出 OMS 升级程序。

   ![升级](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V4.1.0/900.update-oms-05.png)

### 步骤五：验证

1. 确认机器状态

   升级完成后，您可登录 OMS 社区版控制台，在左侧导航栏，单击 **运维监控** > **机器**。在 **机器列表** 页面查看机器列表是否正常。同时，请确认机器的状态均为 **在线**。

2. 确认 OMS 版本

   登录 OMS 社区版控制台后，将光标悬停在页面右上角 **帮助中心**，单击 **关于 OMS**，将弹窗显示 OMS 信息，确认 OMS 版本是否为升级的目标版本。
