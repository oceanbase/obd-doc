# 通过图形化界面升级 OCP

本文介绍如何通过 obd 的图形化界面操作升级 OCP。

## 前提条件

在开始之前，请确保您已满足以下条件：

* 当前待升级 OCP 的版本为社区版 V4.0.3 或之后版本。

* OCP 节点已安装并配置 Java 环境，目前仅支持 JDK1.8 版本。详细操作可参考 [常见问题](../../600.faq.md) 中 **如何配置 Java 环境**。

## 操作步骤

### （可选）步骤一：获取升级所需安装包

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>若您当前机器可以连接外部网络且已启用远程镜像库（<code>obd mirror list</code> 命令查看），可跳过该步骤。</p>
</main>

1. 下载安装包

   访问 [OceanBase 软件下载中心](https://www.oceanbase.com/softwarecenter)，搜索 **OceanBase 云平台**，根据实际情况下载所需安装包。并将安装包上传至 obd 中控机器任一目录下。

2. 解压安装包

   在安装包所在目录下，执行如下命令解压：

   ```shell
   [admin@test001 ~]$ tar -xzf ocp-all-in-one-*.tar.gz
   ```

3. （可选）卸载原 obd

   若机器中存在 obd 且该 obd 是通过 All in One 包安装，您可执行如下命令先卸载当前 obd。

   ```shell
   [admin@test001 ~]$ cd ocp-all-in-one/bin && bash uninstall.sh
   ```

4. 启动安装程序

   在 ocp-all-in-one 安装目录的 `bin` 目录下执行 `install.sh` 脚本启动安装 obd 程序。

   ```shell
   [admin@test001 bin]$ bash install.sh
   ```

   该脚本会安装 obd，并将安装目录下 `rpms` 目录中的所有安装包复制到 obd 的本地镜像库中，同时关闭远程镜像库。执行成功后输出如下，您可复制并执行输出中的 `source ~/.oceanbase-all-in-one/bin/env.sh` 命令以应用环境配置。

   ```shell
   add auto set env logic to profile: /home/admin/.bash_profile

   #########################################################################################
    Install Finished
   =========================================================================================
   Setup Environment:              source ~/.oceanbase-all-in-one/bin/env.sh
   Quick Start:                    obd demo
   Use Web Service to install:     obd web
   Use Web Service to upgrade:     obd web upgrade
   More Details:                   obd -h
   =========================================================================================
   ```

### 步骤二：升级 OCP

1. 启动升级

   ```shell
   [admin@test001 ~]$ obd web upgrade
   ```

   输出如下，浏览器中访问输出中的 IP 地址即可进入升级向导页面，单击 **开始升级**。

   ```shell
   start OBD WEB in 0.0.0.0:8680
   please open http://10.10.10.1:8680/#/updateWelcome
   ```

   <main id="notice" type='explain'>
     <h4>说明</h4>
     <ul>
     <li>
     <p>白屏界面默认使用 8680 端口，您可使用 <code>obd web upgrade -p &lt;PORT&gt;</code> 命令指定端口。</p>
     </li>
     <li>
     <p>在阿里云或其他云环境下，可能出现程序无法获取公网 IP，从而输出内网地址的情况，此 IP 非公网地址，您需要使用正确的地址访问白屏界面。</p>
     </li>
     <li>
     <p><code>obd web</code> 命令绑定在 0.0.0.0 上，在多网卡部署的情况下，您可通过任意一个可访问的 IP 访问白屏界面。</p>
     </li>
     </ul>
   </main>

2. 部署配置

   在部署配置页面选择待升级的 OCP 集群，以及升级的目标版本。系统会自动获取已被 obd 管理的所有集群名称，您可在 **集群名称** 下拉列表选择需要升级的集群。若您需要升级的集群未被当前 obd 接管（如使用 Docker 部署的集群），可手动输入集群名。当集群升级完成后，OBD 将自动接管对应 OCP 集群。

   ![deploy](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V3.2.0/zh-CN/200.ui-operations/800.update-ocp-06.png)

   设置完成后，单击 **下一步** 即可进入 **联通性测试** 页面。

3. 验证 MetaDB 联通性

   当前页面会自动获取 MetaDB 配置信息，您需检查 **连接信息** 部分内容是否与预期待升级环境一致。确认 MetaDB 连接信息无误后，输入 **访问密码** 并单击 **验证**，系统将校验 MetaDB 是否可成功连接。

   ![metadb](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V3.2.0/zh-CN/200.ui-operations/800.update-ocp-07.png)

4. 配置操作系统用户

   验证 MetaDB 联通性后，您需填写操作系统用户以便安装程序进行自动化配置。

   ![user](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V3.2.0/zh-CN/200.ui-operations/800.update-ocp-08.png)

   | 参数  | 说明   |
   |-------|-------|
   | 用户名 | 需提供主机操作系统的用户以便安装程序进行自动化配置，该用户名需具有 sudo 权限。|
   | 密码  | 需输入 **用户名** 的对应密码。当主机已设置免密时，可忽略此项配置。配置后可单击 **验证** 测试用户连通性。  |

   配置完成后，单击 **下一步** 即可进入 **环境预检查** 页面。

5. 环境预检查

   系统会根据 MetaDB 配置信息获取 OCP 相关配置信息，为保证管理功能一致性，升级程序将升级平台管理服务（COP Server）及其管理的所有主机代理服务（OCP Agent）。

   确认 **安装配置** 及 **升级配置信息** 中的升级内容是否满足预期要求，若发现问题可单击 **上一步** 进行修改，确认无误后可单击 **预检查** 进行检查。

   若检查通过，单击 **下一步** 即可开始升级 OCP；若检查失败，支持对失败项进行修复或忽略。

   * 若选择修复，待修复完成后单击 **重新检查**，系统将重新执行环境预检查程序。

   * 若选择忽略，单击 **忽略全部未通过项**，此时未通过的检查项 **检查状态** 将变更为 **已忽略**，可单击 **下一步** 开始升级 OCP。

   <main id="notice" type='notice'>
     <h4>注意</h4>
     <p>忽略全部未通过项可能会导致升级失败，建议您修复检查失败项后再进行下一步。</p>
   </main>

   ![check](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V3.2.0/zh-CN/200.ui-operations/800.update-ocp-12.png)

6. 升级 OCP

   OCP 升级过程中，您可以通过 **升级日志** 模块查看详细升级日志。

   * 若 OCP 升级成功，可在 **升级日志** 中查看 OCP 登录信息，包括 URL、用户名及密码等。

   * 若 OCP 升级失败，请查看日志信息获取失败原因，并联系技术支持同学进行处理。待定位安装失败问题原因且修复问题后，单击 **重新升级**，系统将重新执行失败的升级步骤。

   <main id="notice" type='explain'>
     <h4>说明</h4>
     <p>升级 OCP 的过程会耗时较长，请您耐心等待。</p>
   </main>

   ![upgrade](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V3.2.0/zh-CN/200.ui-operations/800.update-ocp-11.png)
