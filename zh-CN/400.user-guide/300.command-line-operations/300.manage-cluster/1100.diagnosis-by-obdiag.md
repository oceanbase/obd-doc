# 集群诊断

本文介绍如何使用 obd 命令对 OceanBase 集群进行信息收集和诊断。

obd 集成了 Oceanbase Diagnostic Tool（简称: obdiag）工具，obdiag 现有功能包含了对 OceanBase 数据库日志、SQL Audit 以及 OceanBase 数据库进程堆栈等信息的扫描收集，支持通过 obd 实现诊断信息的一键采集。详细 obdiag 信息可参考 [obdiag GitHub 仓库](https://github.com/oceanbase/obdiag)。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <ul>
  <li>
  <p>使用 obd 命令进行信息收集和诊断时，进行信息收集和诊断的 OceanBase 集群需是被 obd 管理的集群，否则 obd 无法获取集群的信息。obd 部署的集群默认由 obd 管理，非 obd 部署的集群可执行接管操作进行接管。接管的详细操作可参见 <a href='../400.takeover-cluster/450.takeover-cluster.md'>使用 obd 接管集群</a>。</p>
  </li>
  <li>
  <p>本文操作中所用命令的详细介绍可参见 <a href="../../../300.obd-command/500.obdiag-command.md">诊断工具命令组</a>。</p>
  </li>
  </ul>
</main>

## 前提条件

参考本文使用 obdiag 命令前，您需先执行 `obd obdiag deploy` 命令安装 obdiag。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>不同 <code>obd obdiag</code> 命令对 OceanBase 数据库和 ODP 版本要求不同，若版本不支持，使用过程中会输出日志提示。</p>
</main>

## 使用示例

### 收集诊断信息

您可通过 `obd obdiag gather` 命令收集 OceanBase 集群的相关信息，命令的详细介绍可参见 [诊断工具命令组](../../../300.obd-command/500.obdiag-command.md) 中的 **obd obdiag gather** 部分。

### 集群巡检

您可使用 `obd obdiag check` 命令进行 OceanBase 数据库集群相关状态的巡检，目前支持从系统内核参数、内部表等方式对 OceanBase 集群进行分析，发现已存在或可能会导致集群出现异常问题的原因分析并提供运维建议。

您可在命令中通过 `--cases` 指定 tasks，可通过 obdiag check list 命令查看支持配置的 tasks。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>支持手动编写 task，详细介绍可参见官网《OceanBase 敏捷诊断工具（obdiag）》文档 <a href="https://www.oceanbase.com/docs/common-obdiag-cn-1000000001102518">一键集群巡检</a> 中 <b>task 编写教程</b> 部分内容。</p>
</main>

```shell
/home/admin/oceanbase-diagnostic-tool/obdiag check list
```
