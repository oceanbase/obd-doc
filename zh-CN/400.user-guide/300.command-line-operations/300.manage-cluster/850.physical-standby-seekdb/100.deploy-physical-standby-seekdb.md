# 创建备实例

本文分为三种场景介绍如何使用 obd 快速创建 seekdb 备实例。

## 概念介绍

主备实例是 seekdb 提供的高可用方案：通过部署只读的备实例从主实例同步数据，当主实例出现计划内或计划外的不可用情况时，备实例可以接管服务，并且提供无损切换（RPO = 0）和有损切换（RPO > 0）两种容灾能力，最大限度降低服务停机时间，减少可能带来的数据损失。

主实例（PRIMARY）是用户创建的业务实例，支持完整的数据库服务能力，包括：查询、DML、DDL 等；备实列（STANDBY）则仅提供容灾和只读服务的能力。

<!-- 详细介绍可参见官网《OceanBase 数据库》文档 [管理数据库/高可用/物理备库容灾](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000002013080) 章节内容。 -->

## 前提条件

* seekdb 主实例为 V1.2.0 或之后版本，且由 obd 管理。

  obd 部署的 seekdb 默认由 obd 管理；若 seekdb 主实例非 obd 部署，可使用 obd 接管对应 seekdb 实例，具体操作可参见 [使用 obd 执行接管](../../400.takeover-cluster/450.takeover-cluster.md) 中 **接管 seekdb 实例** 部分。

* 需保证主实例是正常运行状态，可执行 `obd seekdb display` 命令查看 seekdb 实例状态。

* 简单体验时主实例资源最少为 1C1GB 内存、3GB 日志磁盘，长期使用建议主实例资源为 1C4GB 内存及以上。

## 操作步骤

本节分为如下三个场景介绍创建备实例的操作。

* 场景一：一主一备
  
  一主一备的部署模式简单概括即为：存在 `seekdb_A`、`seekdb_B` 两个 seekdb 实例，`seekdb_A` 实例为主实例，`seekdb_B` 实例为 `seekdb_A` 实例的备实例。

* 场景二：一主两备
  
  一主两备的部署模式简单概括即为：存在 `seekdb_A`、`seekdb_B` 和 `seekdb_C` 三个 seekdb 实例，`seekdb_A` 实例为主实例，`seekdb_B` 和 `seekdb_C` 实例均为 `seekdb_A` 实例的备实例。

* 场景三：级联主备
  
  级联主备的部署模式简单概况即为：存在 `seekdb_A`、`seekdb_B` 和 `seekdb_C` 三个 seekdb 实例，`seekdb_A` 实例为主实例，`seekdb_B` 实例为 `seekdb_A` 实例的备实例，`seekdb_C` 实例为 `seekdb_B` 实例的备实例。

tab 场景一：一主一备
  
1. 创建备实例

   可执行如下命令创建备实例，命令执行后将开启交互式部署流程。需在交互式部署流程中配置 seekdb 备实例信息，并选择主实例的部署名。命令执行的具体介绍可参见 [部署 seekdb](../../200.deploy-component/300.start-the-seekdb-by-using-obd.md) 中 **交互式部署 seekdb** 部分。

   ```shell
   obd seekdb install --standby
   ```

2. 查看 seekdb 实例的主备关系

   ```shell
   obd seekdb display seekdb_B -g
   ```

   `-g` 参数可以展示主备实例拓扑信息，输出如下所示：

   ```shell
   Get local repositories and plugins ok
   Open ssh connection ok
   Connect to seekdb 10.10.10.1:2881 ok
   Wait for seekdb init ok
   +--------------------------------+
   |             seekdb             |
   +---------------+---------+------+
   | ip            | version | port |
   +---------------+---------+------+
   | 10.10.10.1    | 1.2.0.0 | 2881 |
   +---------------+---------+------+
   obclient -h10.10.10.1 -P2881 -uroot -p'********' -Doceanbase -A
   
   Cluster Topology:
   
   seekdb_A
   └── seekdb_B
   ```
