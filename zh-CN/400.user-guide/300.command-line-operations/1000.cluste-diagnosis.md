# 集群诊断

OBD 支持对管理的集群进行诊断，本文介绍具体诊断操作。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>OBD 部署的集群默认由 OBD 管理，非 OBD 部署的集群可执行接管操作进行接管，具体操作可参见 <a href="450.takeover-cluster.md">使用 OBD 接管集群</a>。</p>

## 集群巡检
<!-- 集群巡检和诊断分析的区别是什么 -->
可通过 obd obdiag check 命令进行 OceanBase 集群相关状态巡检，命令的详细介绍可参见 [诊断工具命令组](../../300.obd-command/500.obdiag-command.md) 中 **obd obdiag check**。

1. 创建 task

   task 会包含一些用于巡检的前置声明，用于实现对 OceanBase 集群更为专业的巡检。详细的编写教程可参见官网《OceanBase 敏捷诊断工具（obdiag）》文档 [一键集群巡检](https://www.oceanbase.com/docs/common-obdiag-cn-1000000000791134) 中 **task 编写教程**。
   <!-- obdiag 文档中的 集群巡检指标详解是做什么的时候用到的呀 -->
2. 执行测试

   ```shell
   obd obdiag check test --cases=test
   ```

   输出如下：

   ```shell
   
   ```

参数 `deploy name` 为部署名，可以理解为配置文件的别名。

选项说明见下表：

| 选项名                 | 是否必选 | 数据类型   | 默认值                       | 说明                                                                |
|---------------------|------|--------|---------------------------|-------------------------------------------------------------------|
| --cases | 否 | string | 默认为所有 tasks | 需要执行的巡检项目的集合名。当未赋值时执行所有的 tasks。task 的详细介绍可参见 《OceanBase 敏捷诊断工具》中 [一键集群巡检](https://www.oceanbase.com/docs/common-obdiag-cn-1000000000441294) 一文。 |
| --store_dir | 否 | string | ./check_report/  | 指定报告输出路径。 |
| --obdiag_dir |  否    | string |   $HOME/oceanbase-diagnostic-tool     | obdiag 的安装目录。 |
| --dis_update   | 否    | string |   默认为true              | 预留参数，用于禁止自动更新收集场景配置|
