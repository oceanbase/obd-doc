# 使用 OCP 接管 obd 部署的集群

本文介绍使用社区版 OCP 接管 obd 部署的 OceanBase 集群时，obd 侧需要做哪些工作。

## 前提条件

在开始之前，请确保您已满足以下条件：

* 已安装 obd ，且 obd 版本为 V2.4.0 或之后版本。建议安装最新版本，详细信息请参考 [安装 obd](../../../200.quick-start/100.install-obd.md)。
  
* 已安装社区版 OCP，且 OCP 版本为 V3.1.1 或之后版本，建议安装最新版本。

* 确保待接管的 OceanBase 集群中所有 OBServer 节点都正常运行，且每个 OBServer 节点中只有一个 observer 进程。

  <main id="notice" type='explain'>
    <h4>说明</h4>
    <p>若接管所用 OCP 为 V4.2.0（不含）之前版本，还需确保 observer 进程为 admin 用户启动。</p>
  </main>

## 操作步骤

### 步骤一：检查集群是否满足条件

在使用 OCP 接管 obd 部署的 OceanBase 集群前，您需先使用如下命令检查待接管的 OceanBase 集群是否满足接管条件。如条件不满足，可以根据提示参见下文进行修改。

```shell
obd cluster check4ocp test -V 4.4.0
```

`-V` 用于指定接管所用 OCP 的版本，命令执行输出如下：


### 步骤二：接管集群

1. 上传 ocp-agent 安装包

   您可访问 [阿里云开源镜像站](https://mirrors.aliyun.com/oceanbase/community/stable)，根据自身环境下载所需的 ocp-agent 安装包。下载完成后，浏览器登录 OCP 控制台，单击左侧导航栏 **系统管理** > **软件包管理**。在 **软件包** 页面中，单击页面右上角 **上传** 按钮，单击 **选择软件包**，从本地选择并上传 ocp-agent 安装包。

2. 执行接管命令

   ```shell
   obd cluster export-to-ocp test -a http://10.10.10.1:8080 -u admin -p ********
   ```

   `-a` 用于指定 OCP 地址；`-u` 用于指定 OCP 用户，该用户需要具有接管集群相关操作的权限；`-p` 用于指定用户密码。命令执行输出如下：

   ```shell
   Open ssh connection ok
   Remote oceanbase-ce-utils-4.5.0.0-100000012025112711.el7-eb2f66c9fe4becee1400a6472a6e53e7bd5d8227 repository install ok
   Connect to http://10.10.10.1:8080 ok
   Connect to observer 10.10.10.2:2881 ok
   Configurations of the oceanbase-ce can be taken over by OCP.
   takeover task successfully submitted to ocp, you can check task at http://10.10.10.1:8080/task/25
   Trace ID: 5c4f6ebc-e0a1-11f0-9268-00163e3eb36c
   If you want to view detailed obd logs, please run: obd display-trace 5c4f6ebc-e0a1-11f0-9268-00163e3eb36c
   ```

3. 查看接管进度

   登录 OCP 控制台，之后可单击页面右上角 **任务中心** 进入到 **任务** 页面，查看接管任务的执行进度。

   接管任务完成后，可从左侧导航栏单击 **集群**，在 **集群** 页面可以看到被接管的集群，状态为 **正常运行**。

   ![集群状态](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/obd/V4.0.0/zh-CN/400.OCP-takeover-OBD-deployment-cluster-01.png)

### 步骤三：创建 OBProxy 集群

使用 OCP 接管 OceanBase 集群后，您需新建 OBProxy 集群并关联已接管的 OceanBase 集群，具体步骤请参见官网《OceanBase 云平台》文档 [OBProxy 管理/创建 OBProxy 集群](https://www.oceanbase.com/docs/common-ocp-1000000004276467)。

如果原 ODP 使用了 VIP，可以将 OCP 上新建的 ODP 逐个添加到 VIP 中，再逐个从 VIP 中下线原 ODP。

#### FAQ

1. 切换新的 ODP，可以复用原来的机器吗？

   如果原来部署了多台 ODP 并且通过 VIP 来访问，可以逐个下线，并且用相同的机器在 OCP 中部署 ODP，再添加回 VIP，通过这种方式实现机器复用。

2. 不切换 ODP 是否可以？

   可以的，原 ODP 仍然可以正常连接接管的 OceanBase 集群，但是还是建议用 OCP 新建 ODP 进行替换，方便以后的运维管理。
