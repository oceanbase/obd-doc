# 使用 obd 接管集群

## 前提条件

* 待接管的 OceanBase 集群需为社区版 V4.2.1 BP4 或之后版本，且已启动过 obshell，具体确认操作可参见下文 [查看 OceanBase 集群信息](#查看%20OceanBase%20集群信息)。

* 待接管的 OceanBase 集群处于正常运行状态，查看方法可参见《OceanBase 数据库》文档 [检查 OBServer 状态](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000000639722) 一文。

* obd 所在机器与 OceanBase 集群中的节点网络连通。

## 接管 OceanBase 集群

1. 接管 OceanBase 集群

   ```shell
   [admin@obtest ~]$ obd cluster takeover test -h 10.10.10.1 -P 2881 -p ****** -ssh-user=admin --ssh-key-file=/home/admin/.ssh/id_rsa
   ```

   接管命令的详细介绍可参见 [集群命令组](../../300.obd-command/100.cluster-command-groups.md) 中 **obd cluster takeover**。

2. 通过 obd 查看集群状态

   ```shell
   [admin@obtest ~]$ obd cluster display test
   ```

   输出如下：

   ```shell
   Get local repositories and plugins ok
   Open ssh connection ok
   Cluster status check ok
   Connect to observer 10.10.10.1:2881 ok
   Wait for observer init ok
   +----------------------------------------------+
   |                oceanbase-ce                  |
   +------------+---------+------+-------+--------+
   | ip         | version | port | zone  | status |
   +------------+---------+------+-------+--------+
   | 10.10.10.1 | 4.3.0.1 | 2881 | zone1 | ACTIVE |
   +------------+---------+------+-------+--------+
   obclient -h10.10.10.1 -P2881 -uroot -p'********' -Doceanbase -A
   
   Trace ID: 093ddc0c-039b-11ef-865a-00163e0808cc
   If you want to view detailed obd logs, please run: obd display-trace 093ddc0c-039b-11ef-865a-00163e0808cc
   ```

## 查看 OceanBase 集群信息

1. 使用 root 用户登录待接管 OceanBase 集群的 sys 租户

   ```shell
   [admin@obtest ~]$ obclient -h10.10.10.1 -P2883 -uroot@sys#obdemo -p -c -Doceanbase -A
   ```

   参数说明：

   * -h：提供 OceanBase 数据库连接 IP，通常是一个 ODP 地址。此处以 `10.10.10.1` 为例，您需根据实际情况进行替换。

   * -u：提供租户的连接账户，格式有：`用户名@租户名#集群名`、`集群名:租户名:用户名`、`集群名-租户名-用户名` 或者 `集群名.租户名.用户名`。此处以 `root@sys#obdemo` 为例，您需根据实际情况进行替换。

     <main id="notice" type='explain'>
       <h4>说明</h4>
       <p><ul><li>当使用 ODP 连接 OceanBase 集群时，可以通过以下方式获取集群名：</br>先通过直连的方式连接 OceanBase 数据库，之后使用 <code>SHOW PARAMETERS LIKE 'cluster';</code> 命令来获取集群的名称，该命令的返回结果中 <code>VALUE</code> 的值对应 OceanBase 集群的名称。</li><li>如果 ODP 代理多个集群，连接时必须指定集群名；如果 ODP 只代理一个集群，连接时则不需指定集群名。</li></ul></p>
     </main>

   * -P：提供 OceanBase 数据库连接端口，直连时需配置为 `mysql_port` 值（默认为 `2881`），通过 ODP 连接时需配置为 `listen_port` 值（默认为 `2883`）。此处以 `2883` 为例，您需根据实际情况进行替换。

   * -c：表示在 OBClient 运行环境中不要忽略注释。

      <main id="notice" type='explain'>
        <h4>说明</h4>
        <p>Hint 是特殊的注释，不受 -c 影响。</p>
      </main>

   * -A：表示在 OBClient 连接数据库时不自动获取统计信息。

   * -D：设置要访问的数据库的名称，可以更改为业务数据库。

2. 查看 OceanBase 数据库版本

   ```shell
   obclient [oceanbase]> SELECT OB_VERSION();
   ```

   输出如下：

   ```shell
   +--------------+
   | OB_VERSION() |
   +--------------+
   | 4.3.0.1      |
   +--------------+
   ```

3. 查看 obshell 信息

   ```shell
   obclient [oceanbase]> select * from ocs.all_agent;
   ```

   输出如下，能输出 obshell 信息即表示集群中已启动过 obshell：

   ```shell
   +------------+------+---------------+----------------------+-------+--------------+-------+------------+----------+--------------------------------+------------------------------------------------------------------------------------------------------+
   | ip         | port | identity      | version              | os    | architecture | zone  | mysql_port | rpc_port | home_path                      | public_key                                                                                           |
   +------------+------+---------------+----------------------+-------+--------------+-------+------------+----------+--------------------------------+------------------------------------------------------------------------------------------------------+
   | 10.10.10.1 | 2886 | CLUSTER AGENT | 4.2.3.0-102024031414 | linux | x86_64       | zone1 |       2881 |     2882 | /home/admin/oceanbase-ce       | MEgCQQCoegOM/lKWUfz0ZUOg+KK+bpW7jr16xvQy7foOqZc5yB8F+8J5pNvD0pHNH+2IeG2bIMbhnUbV/B0XeqkACD/xAgMBAAE= |
   +------------+------+---------------+----------------------+-------+--------------+-------+------------+----------+--------------------------------+------------------------------------------------------------------------------------------------------+
   ```
