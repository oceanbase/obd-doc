# 部署 seekdb

本文介绍如何使用 obd 在单台机器上部署 seekdb。

## 前提条件

在开始之前，请确保您已满足以下条件：

* 待部署 seekdb 的服务器满足 [准备服务器](https://www.oceanbase.ai/docs/zh-CN/prepare-servers) 一文中的要求，且已参照 [部署前准备](https://www.oceanbase.ai/docs/zh-CN/configurations-overview) 章节进行配置。

* 您已安装 V4.3.0 或之后版本的 obd，且安装 obd 的机器可以通过 SSH 方式访问待部署 seekdb 的机器。安装操作可参见 [安装 obd](../../../200.quick-start/100.install-obd.md)，建议安装最新版本。
  
  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>若您计划在 obd 节点上部署 seekdb，建议为机器配置本机的 SSH 免密登录，具体操作可参见 <a href="https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000004476409">设置无密码 SSH 登录</a>。</p>
  </main>

* obd 镜像库中存在部署所需组件安装包（seekdb、seekdb-libs），且需为 V1.2.0 或之后版本。

  若 obd 所在机器可以连接外部网络，部署时会自动从远程镜像库获取社区版组件安装包。若 obd 所在机器无法连接外部网络，可访问官网 [OceanBase 软件下载中心](https://www.oceanbase.com/softwarecenter) 下载 seekdb 安装包，并执行 `obd mirror clone` 命令上传至 obd 本地镜像库。上传后可执行 `obd mirror list local` 命令查看本地镜像库中的安装包。

## 操作步骤

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>本文操作以 x86 架构的 CentOS Linux 7.9 镜像作为环境，其他环境可能略有不同。</p>
</main>

tab 交互式部署 seekdb

执行 `obd seekdb install` 命令即可启动交互式部署流程，您需在交互式安装流程中配置如下内容。

1. 选择安装模式

   目前支持三种安装模式：Standalone（单机模式）、Primary（主实例模式）、Standby（备实例模式）。

    :::tab

    tab 单机模式

    未配置选项时，默认使用单机模式部署 seekdb。

    ```shell
    obd seekdb install
    ```

    ```shell

    #设置 SSH 端口，默认为 22

    #设置存储 SSTable 等数据的目录，需确保配置的用户拥有目录的访问和读写权限
    ```

tab 通过配置文件部署 seekdb

### 步骤一：修改配置文件

obd 提供配置文件示例，若您机器中的 obd 是通过直接下载的方式安装，则可在 `/usr/obd/example/seekdb` 目录下查看 obd 提供的 seekdb 配置文件示例。

<!-- 若您机器中的 obd 是通过解压 all-in-one 安装包的方式安装，则可在 `~/.oceanbase-all-in-one/obd/usr/obd/example` 目录下查看 obd 提供的配置文件示例。 -->

<main id="notice" type='explain'>
  <h4>说明</h4>
  <ul>
  <li><p>本文末会提供完整的部署 seekdb 的 <a href="#配置文件示例">配置文件示例</a>，您也可直接复制并进行修改。</p></li>
  <li><p>您需根据您环境的真实情况修改配置文件中参数。</p></li>
  </ul>
</main>

1. 创建配置文件

   ```shell
   vim myseekdb.yaml
   ```

2. 配置用户信息

   ```yaml
   ## Only need to configure when remote login is required
   user:
     username: admin
   #   password: your password if need
     key_file: /home/admin/.ssh/id_rsa
   #   port: your ssh port, default 22
   #   timeout: ssh connection timeout (second), default 30
   ```

   `username` 为登录到目标机器（安装 seekdb 的机器）的用户名，确保您的用户名有下文配置的目录的访问和读写权限。`password` 和 `key_file` 均用于验证用户，通常情况下只需要填写一个。

   <main id="notice" type='notice'>
     <h4>注意</h4>
     <p>在配置秘钥路径后，如果您的秘钥不需要口令，请注释或者删除 <code>password</code>，以免 <code>password</code> 被视为秘钥口令用于登录，导致校验失败。</p>
   </main>

3. 配置 seekdb 的 IP、端口和相关目录，并配置内存相关参数及 root 用户密码

   ```yaml
   seekdb:
     servers:
       - 10.10.10.1
     global:
       home_path: /home/admin/myseekdb
       data_dir: /data/1
       redo_dir: /data/log1
       mysql_port: 2881
       rpc_port: 2882
       obshell_port: 2886
       memory_limit: 12G
       memory_hard_limit: 20G
       datafile_size: 100G
       datafile_maxsize: 300G
       cpu_count: 8
       max_syslog_file_count: 1024
       log_disk_size: 30G
       enable_auto_start: false
       production_mode: false
       root_password: ********
       enable_rpc_service: true
       log_disk_utilization_threshold: 80
   ```

   配置文件中各配置项含义可参见 [配置文件说明](../100.configuration-file-description.md) 一文中 **配置项说明** 部分介绍。需注意如下几点：

   * 配置文件中若未配置密码，obd 会自动生成随机密码，部署成功后可通过 `obd cluster edit-config` 命令查看配置文件中对应的配置项获取密码。

   * 配置 `enable_auto_start` 为 `true` 即表示开启 observer 进程开机自启动功能，该功能需确保部署用户拥有 sudo 权限，且部署环境非容器环境。

## 相关操作

您可执行如下命令对 obd 部署的 seekdb 实例进行管理。更多操作详见 [seekdb 命令组](../../../300.obd-command/150.seekdb-commands.md)。

* 查看 seekdb 实例列表
  
  ```shell
  obd seekdb list
  ```

* 查看 seekdb 实例状态，以部署名为 `myseekdb` 为例
  
  ```shell
  obd seekdb display myseekdb
  ```

* 修改实例参数
  
  obd 支持通过 `obd cluster` 命令组管理 seekdb 实例，您可执行如下命令打开配置文件，修改 seekdb 实例配置。

  ```shell
  obd cluster edit-config myseekdb
  ```

  修改配置并保存退出后，obd 会告知如何使得此次修改生效，复制 obd 输出的命令即可。保存修改后输出如下：

  ```shell
  Search param plugin and load ok
  Search param plugin and load ok
  Parameter check ok
  Save deploy "myseekdb" configuration
  Use `obd cluster reload myseekdb` to make changes take effect.
  ```

  复制执行输出中的 `obd cluster reload myseekdb` 命令即可使修改生效。

* 停止运行中的 seekdb 实例，以部署名为 `myseekdb` 为例

  ```shell
  obd seekdb stop myseekdb
  ```

* 销毁已部署的 seekdb 实例，以部署名为 `myseekdb` 为例
  
  ```shell
  obd seekdb destroy myseekdb
  ```
