# 部署 OCP

本文以 x86 架构的 CentOS Linux 7.9 镜像作为环境介绍如何使用 obd 配置文件部署 OCP。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>目前 obd 仅支持管理 OCP 社区版 V4.2.1 及以上版本，和 OCP 企业版 V4.3.5 及以上版本。</p>
</main>

## 前提条件

* 您的机器中已安装 obd，建议安装最新版本，详细信息请参考 [安装 obd](../../../200.quick-start/100.install-obd.md)。

* 部署 OCP 的用户和机器资源满足部署要求，具体可参见官网《OceanBase 云平台》文档 [安装规划](https://www.oceanbase.com/docs/common-ocp-1000000002078408) 章节。

* 待部署 OCP 的机器中已安装 clockdiff 命令。

* 依赖 OceanBase 数据库部署 OCP 时，需确保 OBServer 节点机器支持 AVX 指令集（仅 x86 架构服务器有此限制）。可执行 `lscpu | grep Flags | grep avx` 命令查看是否支持 AVX 指令集。

  <main id="notice" type='explain'>
    <h4>说明</h4>
    <p>当使用 x86 架构机器时，若待部署的 OceanBase 数据库版本在以下范围中，不再限制机器是否支持 AVX 指令集：</p>
    <ul>
    <li>对于 V4.2.x 版本，要求为 V4.2.5.6 或之后版本。</li>
    <li>对于 V4.3.x 版本，要求为 V4.3.5.4 或之后版本。</li>
    <li>对于 V4.4.x 版本，要求为 V4.4.1.0 或之后版本。</li>
    </ul>
  </main>

* 离线部署场景下，若依赖 OceanBase 数据库部署 OCP，且使用 ARM 架构服务器部署，需查看 OBServer 节点机器是否支持 LSE 指令集，可执行 `lscpu | grep Flags | grep atomics` 命令查看是否支持。若机器不支持 LSE 指令集，需下载带 `nonlse` 的 OceanBase 数据库安装包，并使用 `obd mirror clone` 命令将安装包上传到 obd 本地镜像库。

  <main id="notice" type='explain'>
    <h4>说明</h4>
    <p>OceanBase All in One 包中未包含带有 <code>nonlse</code> 的 OceanBase 数据库安装包。</p>
  </main>

## 配置文件

obd 提供了部署 OCP 所需的配置文件示例，您可根据自身机器资源情况进行修改。

* 若您机器中的 obd 是通过直接下载的方式安装，则可在 `/usr/obd/example` 目录下查看 obd 提供的配置文件示例。

* 若您机器中的 obd 是通过解压 all-in-one 安装包的方式安装，则可在 `~/.oceanbase-all-in-one/obd/usr/obd/example` 目录下查看 obd 提供的配置文件示例。

* 您也可在 obd 的 [GitHub 仓库](https://github.com/oceanbase/obdeploy/tree/master/example) 中查看配置文件示例。

obd 提供的和部署 OCP 相关的配置文件示例有如下几个。

* 单独部署 OCP：ocp-only-example.yaml

* 分布式部署 + ODP + OCP：distributed-with-obproxy-and-ocp-example.yaml

## 操作步骤

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>obd 支持部署社区版和企业版 OCP，本文以部署社区版 OCP 为例介绍部署 OCP 的操作。</p>
</main>

### 步骤一：获取所需安装包

1. 下载安装包

   访问 [OceanBase 软件下载中心](https://www.oceanbase.com/softwarecenter)，搜索 **OceanBase 云平台**，根据实际情况下载所需安装包，并将安装包上传至 obd 中控机器任一目录下。

   若从下载中心无法获取所需版本安装包，可联系技术支持人员获取对应安装包。

2. 解压安装包

   在安装包所在目录下，执行如下命令解压：

   ```shell
   [admin@test001 ~]$ tar -xzf ocp-all-in-one-*.tar.gz
   ```

3. （可选）卸载原 obd

   若机器中存在 obd 且该 obd 是通过 All in One 包安装，您可执行如下命令先卸载当前 obd。

   ```shell
   [admin@test001 ~]$ cd ocp-all-in-one/bin && bash uninstall.sh
   ```

4. 启动安装程序

   在 ocp-all-in-one 安装目录的 `bin` 目录下执行 `install.sh` 脚本启动安装 obd 程序。

   ```shell
   [admin@test001 bin]$ bash install.sh
   ```

   该脚本会安装 obd，并将安装目录下 `rpms` 目录中的所有安装包复制到 obd 的本地镜像库中，同时关闭远程镜像库。执行成功后输出如下，您可复制并执行输出中的 `source ~/.oceanbase-all-in-one/bin/env.sh` 命令以应用环境配置。

   ```shell
   add auto set env logic to profile: /home/admin/.bash_profile

   #########################################################################################
    Install Finished
   =========================================================================================
   Setup Environment:              source ~/.oceanbase-all-in-one/bin/env.sh
   Quick Start:                    obd demo
   Use Web Service to install:     obd web
   Use Web Service to upgrade:     obd web upgrade
   More Details:                   obd -h
   =========================================================================================
   ```

### 步骤二：部署 OCP

本节分为 **单独部署 OCP** 和 **依赖 OceanBase 数据库部署 OCP** 两种方法介绍如何部署 OCP：

* 单独部署 OCP 时，您需先创建 OCP 所用的元数据库，以及对应租户（`ocp_meta` 和 `ocp_monitor`）。创建数据库的详细操作可参见 [单机部署 OceanBase 数据库](200.start-the-oceanbase-cluster-by-using-obd.md) 或 [通过图形化界面部署 OceanBase 集群](../../200.ui-operations/200.use-ui-deploy-oceanbase.md)。创建租户时可根据实际情况手动创建或通过 obd 命令创建。手动创建租户的详细操作可参见 [创建租户](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000000639951)，使用 obd 命令创建租户的详细介绍可参见 [集群命令组](../../../300.obd-command/100.cluster-command-groups.md) 中的 **obd cluster tenant create** 命令。

* 依赖 OceanBase 数据库部署 OCP 时，可在配置文件中同时配置 OceanBase 数据库和 OCP 信息，启动 OCP 时，会根据配置的 OceanBase 数据库信息启动 OCP 的元数据库。

:::tab

tab 单独部署 OCP

1. 创建配置文件

   执行如下命令创建配置文件，此处以 ocp-only-example.yaml 为例，您可自定义配置文件名。

   ```shell
   vim ocp-only-example.yaml
   ```

2. 修改用户信息

   您可复制如下内容，根据自身实际场景进行修改。

   ```yaml
   ## Only need to configure when remote login is required
   user:
     username: admin
   #   password: your password if need
     key_file: /home/admin/.ssh/id_rsa
   #   port: your ssh port, default 22
   #   timeout: ssh connection timeout (second), default 30
   ```

   `username` 为登录到目标机器的用户名，确保您的用户名有家目录的写权限。`password` 和 `key_file` 均用于验证用户，通常情况下只需要填写一个。

   <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>在配置秘钥路径后，如果您的秘钥不需要口令，请注释或者删除 <code>password</code>，以免 <code>password</code> 被视为秘钥口令用于登录，导致校验失败。</p>
   </main>

3. 修改 OCP 配置

   您可复制如下内容，根据自身实际场景进行修改。配置项的具体含义可参见 [配置文件说明](../100.configuration-file-description.md) 中 **配置项说明**。

   ```yaml
   ocp-server-ce:
     # version: 4.2.2
     # package_hash: 84a65bf0ec004e73b772938696b2b896a0ef2b2f
     # release: 20240315150922.el7
     servers:
       - 10.10.10.1
     global:
       home_path: /home/admin/ocp
       soft_dir: /home/admin/ocp/software
       log_dir: /home/admin/ocp/logs
       ocp_site_url: http://10.10.10.1:8080
       port: 8080
       admin_password: ********
       memory_size: 4G
       jdbc_url: jdbc:oceanbase://10.10.10.2:2881/test
       jdbc_username: root@sys
       jdbc_password: ********
       ocp_meta_tenant:
         tenant_name: ocp_meta
         max_cpu: 2.0
         memory_size: 4G
       ocp_meta_username: root
       ocp_meta_password: ********
       ocp_meta_db: meta_database
       ocp_monitor_tenant:
         tenant_name: ocp_monitor
         max_cpu: 2.0
         memory_size: 4G
       ocp_monitor_username: root
       ocp_monitor_password: ********
       ocp_monitor_db: monitor_database
   ```

4. 部署 OCP

   ```shell
   obd cluster deploy ocp -c ocp-only-example.yaml
   ```

   命令里的 `ocp` 为集群名，您可根据实际情况自定义集群名。部署成功后命令行会输出对应的启动命令，输出如下：

   ```shell
   ocp deployed
   Please execute ` obd cluster start ocp ` to start
   Trace ID: 4e444844-0211-11ef-8e69-00163e0808cc
   If you want to view detailed obd logs, please run: obd display-trace 4e444844-0211-11ef-8e69-00163e0808cc
   ```

5. 启动 OCP

   ```shell
   obd cluster start ocp
   ```

   启动成功后会输出 OCP 的登录信息，输出如下：

   ```shell
   +----------------------------------------------------------+
   |                      ocp-server-ce                       |
   +---------------------------+----------+----------+--------+
   | url                       | username | password | status |
   +---------------------------+----------+----------+--------+
   | http://10.10.10.1:8080    | admin    | ******** | active |
   +---------------------------+----------+----------+--------+
   ocp running
   Trace ID: ed5a1f4c-0218-11ef-bda1-00163e0808cc
   If you want to view detailed obd logs, please run: obd display-trace ed5a1f4c-0218-11ef-bda1-00163e0808cc
   ```
