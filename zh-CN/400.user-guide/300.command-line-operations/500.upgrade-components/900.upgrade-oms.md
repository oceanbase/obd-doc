# 升级 OMS

本文介绍如何通过 obd 的图形化界面操作升级 OMS。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>目前 obd 仅支持升级 OMS 社区版。</p>
</main>

## 前提条件

在开始之前，请确保您已满足以下条件：

* 待升级的 OMS 的部署方式为使用 obd 部署。

* 您已安装 obd V4.0.0 或之后版本，建议安装最新版本，详细信息请参考 [安装 obd](../../200.quick-start/100.install-obd.md)。

## 操作步骤

### 步骤一：获取升级所需安装包

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>如待升级的 OMS 为多节点 OMS，每个节点都需要执行如下操作。</p>
</main>

1. 下载安装包

   访问 [OceanBase 软件下载中心](https://www.oceanbase.com/softwarecenter)，搜索 **OceanBase 迁移服务**，根据实际情况下载所需安装包，并将安装包上传至 obd 中控机器任一目录下。

   若从下载中心无法获取所需版本安装包，可联系技术支持人员获取对应安装包。

2. 加载下载的 OMS 安装包至 Docker 容器的本地镜像仓库

   ```shell
   [admin@test001 ~]$ sudo docker load -i oms_4.2.11-ce.tar.gz
   ```

3. 验证加载是否成功

   ```shell
   [admin@test001 ~]$ sudo docker images
   ```

   输出如下：

   ```shell
   REPOSITORY                                    TAG                 IMAGE ID       CREATED        SIZE
   reg.docker.alibaba-inc.com/oceanbase/oms-ce   feature_4.2.11_ce   26f5f1554fc5   2 months ago   12.5GB
   reg.docker.alibaba-inc.com/oceanbase/oms-ce   feature_4.2.12_ce   28fddcdaf8a0   2 days ago     12.5GB
   ```

### 步骤二：升级 OMS

1. 执行升级命令

   ```shell
   obd cluster upgrade myoms -c oms --tag=feature_4.2.13_ce --image-name=reg.docker.alibaba-inc.com/oceanbase/oms-ce
   ```
