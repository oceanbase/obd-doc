# OceanBase 安装部署工具 V3.4.0

## 版本信息

* 发布时间：2025 年 07 月 14 日

* 版本号：V3.4.0

* RPM 版本号：ob-deploy-3.4.0-2

## 新增特性

* `obd cluster deploy` 命令新增 `-i` 选项，通过向导式交互简化配置流程。具体操作可参见 [部署 OceanBase 集群](../../400.user-guide/300.command-line-operations/200.deploy-component/200.start-the-oceanbase-cluster-by-using-obd.md)。

* 新增单机最大资源快速部署命令 `obd pref`，一键完成高性能单机环境部署。具体命令介绍可参见 [快速部署命令](../../300.obd-command/000.obd-demo.md)。

* 优化 Oracle 模式租户管理：支持用户密码自定义设置，适配更多业务场景需求。

* 支持通过 `obd tool install` 命令将 OBClient 进行全局安装，无需再次环境配置，提升客户端使用易用性。

## 问题修复

* 修复基于归档的多级主备租户 Switchover 时，结构不符合预期的问题。

* 修复修改 ODP 组件 `listen_port` 参数后重启不生效的问题。
