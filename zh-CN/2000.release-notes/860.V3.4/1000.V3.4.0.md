# OceanBase 安装部署工具 V3.4.0

## 版本信息

* 发布时间：2025 年 07 月 11 日

* 版本号：V3.4.0

* RPM 版本号：ob-deploy-3.4.0-2

## 发版目的

* `obd cluster deploy` 命令新增 `-i` 选项，支持交互式部署集群。具体操作可参见 [单机部署 OceanBase 集群](../../400.user-guide/300.command-line-operations/200.deploy-component/200.start-the-oceanbase-cluster-by-using-obd.md)。

* 新增单机最大资源快速部署命令 `obd pref`，具体命令介绍可参见 [快速部署命令](../../300.obd-command/000.obd-demo.md)。

* 支持为 Oracle 模式租户设置用户密码和场景优化。

* 支持通过 `obd tool install` 命令将 OBClient 进行全局安装。

## 问题修复

* 修复基于归档的多级主备租户 Switchover 时，结构不符合预期的问题。

* 修复修改 ODP 组件 `listen_port` 参数后重启不生效的问题。
