# OceanBase 安装部署工具 V3.0.0

## 版本信息

* 发布时间：2024 年 12 月 12 日

* 版本号：V3.0.0

* RPM 版本号：ob-deploy-3.0.0-3

## 发版目的

* 适配 OceanBase 数据库社区版 V4.2.5.1

* 系统架构升级，引入 workflow 编排机制

* 优化低性能机器环境的安装部署体验

* 优化自动生成配置逻辑

* 修复使用 obd 部署多节点 OCP 时，为 OCP 配置 launch_user（运行用户）的情况下，启动 OCP 集群报错的问题

* 修复日志脱敏存在遗漏的问题
