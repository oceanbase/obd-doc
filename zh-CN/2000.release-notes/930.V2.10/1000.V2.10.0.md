# OceanBase 安装部署工具 V2.10.0

## 版本信息

* 发布时间：2024 年 09 月 03 日

* 版本号：V2.10.0

* RPM 版本号：ob-deploy-2.10.0-3

## 新增特性

* 适配 OceanBase-CE 数据库 V4.3.3。

* 适配 OBProxy V4.3.1。

* 支持在图形化界面下进行组件管理，详细介绍可参见 [通过图形化界面变更组件](../../400.user-guide/200.ui-operations/600.component-change-by-ui.md)。

* 支持图形化部署 OceanBase 数据库时选择业务类型，详细介绍可参见 [通过图形化界面部署 OceanBase 集群](../../400.user-guide/200.ui-operations/200.use-ui-deploy-oceanbase.md) 中 **步骤二：部署配置** 部分。

* 优化 `obd cluster edit-config` 命令逻辑，避免用户错误地重部署集群。

* 优化 `obd cluster restart` 传参逻辑，避免误覆盖用户配置。

* 优化磁盘占用逻辑。

* 创建租户支持打印连接信息。

* 测试命令组中命令支持自动安装工具包。

* 支持使用 `obd test sysbench` 命令同时执行多场景和多线程测试，详细介绍可参见 [测试命令组](../../300.obd-command/300.test-command-group.md) 中 **obd test sysbench**。

* 支持使用 `obd test tpch` 命令执行 TPC-H 测试时通过旁路导入数据，详细介绍可参见 [测试命令组](../../300.obd-command/300.test-command-group.md) 中 **obd test tpch**。

* 支持部署 OBAgent 时指定 monitor_user。

* 日志自动脱敏。

## 问题修复

* 修复部署 OCP 自动接管 MetaDB 时 ssh 端口非预期的问题。

* 修复重启 OCP 时传参非预期的问题。

* 修复部署 OceanBase 数据库时配置已有 obconfig_url 未生效的问题。

* 修复特定场景下对 OCP 执行 `obd cluster destroy` 命令时删除目录报错的问题。

* 修复升级时遇到程序中断情况后重新升级的非预期问题。
