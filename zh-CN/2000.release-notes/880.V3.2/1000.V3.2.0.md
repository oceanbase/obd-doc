# OceanBase 安装部署工具 V3.2.0

## 版本信息

* 发布时间：2025 年 04 月 01 日

* 版本号：V3.2.0

* RPM 版本号：ob-deploy-3.2.0-2

## 新增特性

* 适配 OceanBase 数据库单机版 V4.2.5.3。
* 支持密码密文存储，具体可参见 [密码命令组](../../300.obd-command/590.pwd-commands.md)。
* 支持备份恢复，具体可参见 [备份与恢复](../../400.user-guide/300.command-line-operations/1200.backup-and-recovery.md)。
* 支持初始化系统参数，具体可参见 [obd cluster init4env](../../300.obd-command/100.cluster-command-groups.md)。
* 支持 OceanBase 数据库开机自启动。
* 适配企业版 OCP。
* 支持 OceanBase Binlog 服务升级。
* 支持创建租户时设置密码，具体可参见 [obd cluster tenant create](../../300.obd-command/100.cluster-command-groups.md)。

## 问题修复

* 修复修改 Grafana 密码不生效的问题。
* 修复白屏自动修复按钮失效的问题。
* 修复部署 OCP 时租户资源计算不准确的问题。
* 修复白屏部署 OCP 时，选择使用已有 OceanBase 数据库作为 OCP 的 MetaDB 这一方式部署时，页面会出现短暂白屏的问题。
* 修复通过 Docker 部署的 OCP 升级为 RPM 包部署时，镜像未停止的问题。
