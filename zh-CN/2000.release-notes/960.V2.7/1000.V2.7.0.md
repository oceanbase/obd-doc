# OceanBase 安装部署工具 V2.7.0

## 版本信息

* 发布时间：2024 年 03 月 28 日

* 版本号：V2.7.0

## 新增特性

* 支持安装和管理工具类软件（OBClient、obdiag），详细介绍可参见 [工具命令组](../../300.obd-command/400.tools-commands.md)。

* 优化 OCP 和 OCP Express 的部署体验，支持自动安装 JRE。

* 适配 OceanBase 数据库 V4.3.0，支持部署和创建租户时通过指定负载类型调优。

* 适配 oblogproxy V2.0.1_BP1。

* 适配 OBProxy V4.2.3，新增配置项 `client_session_id_version` 和 `proxy_id` 支持设置全局唯一 Client Session ID。配置项的详细介绍可参见 [配置文件说明](../../400.user-guide/300.command-line-operations/100.configuration-file-description.md) 中对 ODP 配置项的介绍。

* 适配 OCP V4.2.2 密码规范。

* 适配 obdiag V1.6，新增 `obd obdiag gather scene run` 和 `obd obdiag rca run` 命令，详细介绍可参见 [诊断工具命令组](../../300.obd-command/500.obdiag-command.md)。

* 增强容量类型单位适配能力，如 GB、G 等单位将根据组件自适应。

* 优化销毁 OCP 时元数据清理逻辑。

* 优化执行 `obd cluster autodeploy` 命令时组件资源计算逻辑。

* 优化 OCP clockdiff 预检查能力。

## 问题修复

* 修复部署 OCP Express 时未保存租户密码的问题。

* 修复首次 SSH 指纹认证因需要手动输入确认而导致的部署失败问题。

* 修复通过组件变更命令，删除 OCP Express 后再新增 OCP Express 时未清理密码的问题。

* 修复特定场景中部署 OCP 磁盘被打满的问题。

* 修复部署 OBAgent 时 IP 检查非预期的问题。

* 修复图形化界面安装 OCP 时 `ocp_site_url` 传递异常的问题。
