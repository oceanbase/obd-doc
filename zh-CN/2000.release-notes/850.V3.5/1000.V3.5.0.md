# OceanBase 安装部署工具 V3.5.0

## 版本信息

* 发布时间：2025 年 08 月 15 日

* 版本号：V3.5.0

* RPM 版本号：ob-deploy-3.5.0-5

## 新增特性

* 增强 `obd host init` 命令功能：支持关闭防火墙和 SELinux，调整内核参数等。具体介绍可参见  [主机命令组](../../300.obd-command/570.host-commands.md)。

* 新增 `obd host user init` 命令：支持创建用户，设置密码，修改 ulimit 等。命令详细介绍可参见 [主机命令组](../../300.obd-command/570.host-commands.md)。

* 新增 obshell Dashboard 连接信息展示。obshell Dashboard 的具体介绍可参见官网《OceanBase 数据库》文档 [obshell Dashboard](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000003382051) 章节。

* 适配 Oracle 租户场景优化。

## 问题修复

* 修复交互式安装场景下自定义端口报错的问题。

* 修复交互式安装场景下，国产麒麟操作系统 CPU 获取失败的问题。

* 修复 `observer_sys_password` 参数非预期的 warning 问题。

* 修复创建基于归档模式的备租户异常报错的问题。
