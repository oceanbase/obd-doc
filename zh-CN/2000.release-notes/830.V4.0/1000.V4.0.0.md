# OceanBase 安装部署工具 V4.0.0

## 版本信息

* 发布时间：2025 年 11 月 17 日

* 版本号：V4.0.0

* RPM 版本号：ob-deploy-4.0.0-10

## 新增特性

* 支持安装部署以及升级社区版 OMS。

* 全面适配企业版 Binlog Service，实现安装、启动、升级、重启、销毁 obbinlog 集群，以及创建 Binlog 实例等管控功能。

* 适配 OceanBase-ce 升级到 4.4.x 版本。

* 可视化组件变更支持 OceanBase 数据库单机版，包括安装或卸载 Alertmanager、Prometheus 等工具。

* 支持自动注册 Alertmanager 和 Prometheus 配置信息到 obshell Dashboard。

* 实现 Alertmanager 支持 slack 通知方式。

* 优化集群自定义参数配置展示顺序如 `cpu_cout`、`memory_limit`、`datafile_size` 等，方便用户快速操作。

* 交互式部署时支持展示租户更多信息，如字符集、字符序、时区、大小写敏感（MySQL 租户）。

* 支持集群 `destroyed` 和 `configured` 状态下变更集群配置文件。

* 新增 `obd cluster prune-config` 命令，支持清理 `destroyed` 和 `configured` 状态集群的配置文件。

* 通过 `Docp.host.ip=xxx` 实现 OCP 单机多网卡场景下的真实 IP 地址配置。

## 产品行为变更

* 变更 OB-Dashboard 为 obshell Dashboard。

* `obd host init` 仅在单机企业版时检查/修改 `net.ipv4.ip_forward`，避免造成 Docker 环境下网络访问异常。

## 问题修复

* 修复已发现的安全问题，针对 obd 使用的基础框架、运行环境等进行了升级。

  * 升级 Node 版本到 20.19.5。

  * 升级 Python 版本到 3.11。

* 修复 `obd host user init` 命令在特殊场景下执行报错的问题。

* 修复通过图形化页面卸载 ocp-server-ce 组件，页面没有显示组件名的问题。
