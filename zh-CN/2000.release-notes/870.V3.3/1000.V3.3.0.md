# OceanBase 安装部署工具 V3.3.0

## 版本信息

* 发布时间：2025 年 06 月 06 日

* 版本号：V3.3.0

* RPM 版本号：ob-deploy-3.3.0-1

## 发版目的

* 适配 OceanBase 数据库社区版 V4.3.5.2。

* 新增基于归档的备租户部署运维，具体操作可参见 [主备租户](../../400.user-guide/300.command-line-operations/300.manage-cluster/800.physical-standby-database/100.deploy-physical-standby-database.md) 章节。

* 支持通过图形化界面部署 OceanBase 数据库单机版和商业版。

* 支持通过图形化界面创建业务租户，具体操作可参见 [部署 OceanBase 集群](../../400.user-guide/200.ui-operations/200.use-ui-deploy-oceanbase.md) 中 **步骤七：创建业务租户**。

* 支持通过图形化界面部署 Prometheus 和 Granfana。

* 支持部署 ODP 时配置 VIP/DNS。

## 问题修复

* 修复通过图形化界面安装时，安装报告中用户名展示不规范的问题。

* 修复新增组件时，校验目录非预期的问题。
