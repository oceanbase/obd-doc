# 主机命令组

obd 自 V3.2.0 起支持对机器的系统参数进行查看和修改，本文介绍功能相关的命令组。您可以在每条命令中使用 `-h`/`--help` 选项查看命令的帮助信息。同样的，当命令执行报错时，您亦可使用 `-v`/`--verbose` 查看命令的详细执行过程。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>本文中的 <b>目标机器</b> 指待查看或修改系统参数的机器。</p>
</main>

## obd host precheck

使用该命令可查看部署 OceanBase 数据库时建议修改的系统参数。

```shell
obd host precheck <username> <server ip>

#example
obd host precheck root 10.10.10.1
```

参数 `username` 为目标机器中的用户名；`server ip` 为目标机器的 IP，目前仅支持配置一个 IP。

若目标机器中对应用户配置有密码，且未设置当前 obd 机器与目标机器之间的 SSH 免密，需通过 `-p`/`--password` 选项指定用户密码。

## obd host init

使用该命令可修改 `obd host precheck` 命令查出的系统参数。

```shell
obd host init <username> <server ip>

#example
obd host init root 10.10.10.1
```

参数 `username` 为登录目标机器的用户名，需确保登录用户拥有 sudo 权限；`server ip` 为目标机器的 IP，目前仅支持配置一个 IP。

若目标机器中对应用户配置有密码，且未设置当前 obd 机器与目标机器之间的 SSH 免密，需通过 `-p`/`--password` 选项指定用户密码。
