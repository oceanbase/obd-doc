# 快速部署命令

## obd demo

使用该命令可在不传入配置文件的情况下直接在本机部署并启动指定的组件，固定部署名 `demo`，部署后使用命令 `obd cluster list` 查看集群列表时可以查看到该集群，也可以通过其他的集群命令进行管理，比如 `obd cluster display demo` 等。

```bash
obd demo [-c/--components] 
```

选项说明见下表：

|    选项名         | 是否必选 |  数据类型  |  默认值  |                 说明                                               |
|------------------|---------|------------|----------|--------------------------------------------------------------------|
| -c/--components   | 否    | string | oceanbase-ce,obproxy-ce,obagent,prometheus,grafana    | 组件列表，使用英文逗号（`,`）间隔。用于指定需要部署的组件。          |

该命令默认在当前用户的家目录下进行最小规格部署，部署的组件版本默认为最新版本。当前支持组件为：oceanbase-ce、obproxy-ce、obagent、grafana、prometheus、ob-configserver、ocp-express。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>obd 自 V2.8.0 起支持使用 <code>obd demo</code> 命令部署 ocp-express 组件，自 V2.9.0 起支持使用 <code>obd demo</code> 命令部署 ob-configserver 组件。</p>
</main>

## 示例

使用时可以通过选项控制部署版本和配置，具体如下。

### 指定组件

* 部署 OCP Express

  因 OCP Express 的部署依赖于 OceanBase 数据库和 OBAgent，所以使用 demo 部署 OCP Express 时需同时指定 oceanbase-ce 和 obagent。

  ```shell
  obd demo -c oceanbase-ce,obagent,ocp-express
  ```

* 仅部署 obconfigserver

  ```shell
  obd demo -c ob-configserver
  ```

### 指定组件版本

* 指定组件版本部署

  ```shell
  obd demo -c oceanbase-ce,obproxy-ce --oceanbase-ce.version=4.0.0.0
  ```

* 指定组件 hash 部署

  ```shell
  obd demo -c oceanbase-ce,obproxy-ce --oceanbase-ce.package_hash=f38723204d49057d3e062ffad778edc1552a7c114622bf2a86fea769fbd202ea
  ```

### 自定义组件配置

本节以指定组件安装路径和组件端口为例，如需了解配置文件中的相关配置项可参考 [配置文件说明](../400.user-guide/100.configuration-file-description.md) 一文中 **配置项说明** 部分。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>该命令只支持通过选项传入一级配置（即 <code>global</code> 下第一级配置）。</p>
</main>

* 统一指定组件安装路径

  将 oceanbase-ce 和 obproxy-ce 部署到 /data/demo 下并根据组件建立对应的工作目录。

  ```shell
  obd demo -c oceanbase-ce,obproxy-ce --home_path=/data/demo
  ```

* 指定特定组件的安装路径

  将 oceanbase-ce 部署到家目录下并根据组件建立对应的工作目录，而 obproxy-ce 部署到 /data/demo/obproxy-ce。

  ```shell
  obd demo -c oceanbase-ce,obproxy-ce --obproxy-ce.home_path=/data/demo/
  ```

* 指定组件端口

  ```shell
  obd demo --oceanbase-ce.mysql_port=3881
  ```
