# 诊断工具命令组

OceanBase Diagnostic Tool（简称: obdiag）是一款适用于 OceanBase 的黑屏诊断工具，obdiag 现有功能包含了对于 OceanBase 日志、SQL Audit 以及 OceanBase 进程堆栈等信息进行的扫描、收集和分析，可以在 OceanBase 集群不同的部署模式下（OCP，obd 或用户根据文档手工部署）实现一键执行，完成诊断信息的展示、收集和分析。obdiag 代码完全开源，详细 obdiag 信息可参见 [obdiag GitHub 仓库](https://github.com/oceanbase/obdiag)。

obd 集成了 obdiag 工具，支持通过 `obd obdiag` 命令实现一键诊断，执行 `obd tool install obdiag` 命令安装 obdiag 后即可使用。命令执行时需配置的选项与 obdiag 原本选项一致，不同点在于：执行命令时需在 `obdiag` 字段前加上 `obd` 字段，且需在命令中指定集群部署名（可执行 `obd cluster list` 命令查看，`Name` 列输出即为集群部署名），如 `obd obdiag rca run <deploy_name>`。

obdiag 支持的命令和功能介绍可参见官网 [OceanBase 敏捷诊断工具（obdiag）](https://www.oceanbase.com/docs/obdiag-cn) 文档。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>obd obdiag 命令仅支持对 obd 管理的集群进行操作，obd 部署的集群默认由 obd 管理，非 obd 部署的集群可执行接管操作进行接管，具体操作可参见 <a href="../400.user-guide/300.command-line-operations/400.takeover-cluster/450.takeover-cluster.md">使用 obd 接管集群</a>。</p>
</main>

## 使用示例

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>此处仅介绍简单操作，更多示例可参见 <a href="../400.user-guide/300.command-line-operations/300.manage-cluster/1100.diagnosis-by-obdiag.md">集群诊断</a> 一文。</p>
</main>

1. 安装 obdiag

   ```shell
   obd tool install obdiag
   source ~/oceanbase-diagnostic-tool/init.sh
   ```

2. 查看 obd 管理的集群列表

   ```shell
   obd cluster list
   ```

   输出如下：

   ```shell
   +------------------------------------------------------------------+
   |                          Cluster List                            |
   +-------------+----------------------------------+-----------------+
   | Name        | Configuration Path               | Status (Cached) |
   +-------------+----------------------------------+-----------------+
   | obtest      | /home/admin/.obd/cluster/obtest  | running         |
   | demo        | /home/admin/.obd/cluster/demo    | running         |
   +-------------+----------------------------------+-----------------+
   ```

3. 收集集群日志

   此处以收集 `obtest` 集群最近三十分钟的日志为例，且指定在 observer 日志中查询关键字 `STORAGE`。

   ```shell
   obd obdiag gather log obtest --since=30m --scope observer --grep STORAGE
   ```
