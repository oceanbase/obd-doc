# 快速部署 OceanBase 数据库

安装 obd 后，您可执行 `obd demo` 或 `obd perf` 命令快速部署本地单节点 OceanBase 数据库。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>本文操作仅用于快速体验 OceanBase 数据库，如需在生产环境下部署 OceanBase 数据库，具体操作可参见 <a href="../400.user-guide/200.ui-operations/200.use-ui-deploy-oceanbase.md">通过图形化界面部署 OceanBase 集群</a>。</p>
</main>

## 前提条件

在开始之前，请确保您已满足以下条件：

* 使用 x86 架构服务器部署时，需确保 OBServer 节点机器支持 AVX 指令集。可执行 `lscpu | grep Flags | grep avx` 命令查看是否支持 AVX 指令集。
  
  <main id="notice" type='explain'>
    <h4>说明</h4>
    <p>当使用 x86 架构机器时，若待部署的 OceanBase 数据库版本在以下范围中，不再限制机器是否支持 AVX 指令集：</p>
    <ul>
    <li>对于 V4.2.x 版本，要求为 V4.2.5.6 或之后版本。</li>
    <li>对于 V4.3.x 版本，要求为 V4.3.5.4 或之后版本。</li>
    <li>对于 V4.4.x 版本，要求为 V4.4.1.0 或之后版本。</li>
    </ul>
  </main>

* 离线部署场景下，使用 ARM 架构服务器部署时，需查看 OBServer 节点机器是否支持 LSE 指令集，可执行 `lscpu | grep Flags | grep atomics` 命令查看是否支持。若机器不支持 LSE 指令集，需下载带 `nonlse` 的 OceanBase 数据库安装包，并使用 `obd mirror clone` 命令将安装包上传到 obd 本地镜像库。
  
  <main id="notice" type='explain'>
    <h4>说明</h4>
    <p>OceanBase All in One 包中未包含带有 <code>nonlse</code> 的 OceanBase 数据库安装包。</p>
  </main>

* 您已安装 obd，建议安装最新版本。安装 obd 的详细操作您可参见 [安装 obd](100.install-obd.md)。
  
  <main id="notice" type='explain'>
     <h4>说明</h4>
     <p>建议通过下载 OceanBase All in One 进行安装，OceanBase All in One 目前提供部署所需要的全部组件（除 obbinlog 组件），且组件已经经过相互适配测试，为官方推荐版本。</p>
  </main>

* 部署组件的默认端口未被占用，各组件的默认端口可参见 [【SOP 系列 20】OceanBase 服务端进程 & 生态产品默认端口号](https://ask.oceanbase.com/t/topic/35603118)。

* 仅部署 OceanBase 数据库，至少需要 2vCPU、6 GB 内存、20 GB 磁盘的可用资源。需要注意，要求中的内存限制是指执行 `free -g` 命令后，输出中的 `available` 列对应的值。

* 部署默认组件时，至少需要 2vCPU、6 GB 内存、25 GB 磁盘的可用资源。需要注意，要求中的内存限制是指执行 `free -g` 命令后，输出中的 `available` 列对应的值。

* 部署全部组件时，至少需要 4vCPU、10 GB 内存、25 GB 磁盘的可用资源，推荐内存在 16 GB 以上。需要注意，要求中的内存限制是指执行 `free -g` 命令后，输出中的 `available` 列对应的值。

* 您的机器可以联网，或者 obd 本地镜像库中有部署所需安装包。
  
  可执行 `obd mirror list local` 命令查看本地镜像库中的安装包。若您通过 OceanBase All in One 安装 obd，本地镜像库中默认包含所有部署所需组件的安装包。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <ul>
  <li>
  <p>在 CPU 核心数较少的环境中，obd 默认设置的最低 CPU_Count 为 8。CPU 核心数配置过低会对 OceanBase 数据库的性能产生负面影响。</p>
  </li>
  <li>
  <p><code>obd demo</code> 和 <code>obd perf</code> 命令的详细介绍可参见文档 <a href="../300.obd-command/000.obd-demo.md">快速部署命令</a>。</p>
  </li>
  </ul>
</main>

## 示例

* 以最小规格部署社区版 OceanBase 数据库
  
  ```shell
  obd demo -c oceanbase-ce
  ```

* 以最大规格部署社区版 OceanBase 数据库
  
  ```shell
  obd perf -c oceanbase-ce
  ```

* 以最小规格部署默认组件
  
  执行 `obd demo` 命令后，会自动部署社区版 OceanBase 数据库、社区版 OBProxy、OBAgent、Prometheus 和 Grafana，默认版本为镜像库中最新版本。
  
  ```shell
  obd demo
  ```

* 以最大规格部署默认组件，并指定 OceanBase 数据库版本
  
  执行 `obd perf` 命令后，会自动部署社区版 OceanBase 数据库、社区版 OBProxy、OBAgent、Prometheus 和 Grafana，默认版本为镜像库中最新版本。此处示例指定 OceanBase 数据库版本为 V4.3.3.0。

  ```shell
  obd perf --oceanbase-ce.version=4.3.3.0
  ```

部署成功后可复制输出中的连接串，使用 OBClient 客户端连接到 OceanBase 数据库。示例如下：

```shell
obclient -h127.0.0.1 -P2881 -uroot@sys -p'*******'  -Doceanbase -A
```

连接串的详细介绍可参见官网《OceanBase 数据库》文档 [通过 OBClient 连接 OceanBase 租户](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000001574085)。
